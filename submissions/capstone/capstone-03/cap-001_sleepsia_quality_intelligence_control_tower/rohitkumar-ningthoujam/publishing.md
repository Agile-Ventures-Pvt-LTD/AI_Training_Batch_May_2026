# Publishing

## Publishing Channels

The Quality Intelligence Control Tower is intended to be published through:

- Microsoft Teams
- Microsoft 365 Copilot

## Publishing Steps

1. Open the Quality Supervisor agent in Microsoft Copilot Studio.
2. Publish the latest version of the agent.
3. Open **Channels**.
4. Select **Teams and Microsoft 365 Copilot**.
5. Enable Microsoft 365 Copilot availability where tenant permissions and licensing allow.
6. Add the channel.
7. Install and test the agent in Microsoft Teams.
8. Test the agent in Microsoft 365 Copilot where available.
9. Capture screenshots as publishing evidence.

## Validation

The published agent should be tested for:

- Quality investigation queries in Teams.
- Open incident and policy queries.
- Final quality decision responses.
- CAPA status and ownership queries.
- Microsoft 365 Copilot access where enabled.

## Tenant Limitation

Teams and Microsoft 365 Copilot availability depends on organizational permissions, sharing settings, licensing, and Teams/Power Platform policies.

If Microsoft 365 Copilot cannot be enabled because of tenant restrictions, configuration screenshots and the exact limitation should be documented.

## Publishing Status

The agent was published/tested in the available Microsoft 365 environment.
