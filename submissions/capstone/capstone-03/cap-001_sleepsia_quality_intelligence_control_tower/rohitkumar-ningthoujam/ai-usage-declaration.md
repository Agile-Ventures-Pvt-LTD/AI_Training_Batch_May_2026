# AI Usage Declaration

## AI Tools Used

ChatGPT was used during the development and documentation of this solution.

## Usage

ChatGPT was used for:

- Documentation structure and drafting.
- Understanding and organizing PRD requirements.
- Designing and refining Copilot Studio topic flows.
- Supporting topic-flow instructions and branch logic.
- Assisting with tool and agent instruction design.
- Reviewing documentation for consistency and completeness.

## Human Validation

The Copilot Studio implementation, agent configuration, topics, tools, testing, and final validation were performed and verified by the project developer.

AI-generated suggestions were reviewed and adapted to the actual Copilot Studio implementation and project requirements before submission.
