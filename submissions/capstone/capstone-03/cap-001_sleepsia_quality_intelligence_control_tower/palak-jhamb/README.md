# Project Summary

The **Sleepsia Quality Intelligence Control Tower** is an enterprise-grade Microsoft Copilot Studio solution designed to automate product quality investigations through a Supervisor–Specialist architecture.

The solution coordinates multiple specialist agents, validates incidents, applies deterministic quality decision rules, generates Corrective and Preventive Action (CAPA) plans, performs selective reassessment when new evidence is received, updates enterprise records, generates investigation reports, and notifies stakeholders.

The system integrates Microsoft Copilot Studio, Microsoft Dataverse, Power Automate, Microsoft 365 services, and enterprise knowledge sources to provide a complete, policy-compliant, and audit-ready investigation workflow.
