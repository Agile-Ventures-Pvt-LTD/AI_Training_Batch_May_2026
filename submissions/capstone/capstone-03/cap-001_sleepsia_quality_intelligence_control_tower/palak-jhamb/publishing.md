# Publishing

## Overview

The Sleepsia Quality & Customer Experience Intelligence Control Tower was developed and tested in **Microsoft Copilot Studio**. The solution is designed to be published to Microsoft 365 channels such as Microsoft Teams after validation.

---

# Publishing Process

The intended publishing workflow is:

1. Complete development and testing in Microsoft Copilot Studio.
2. Validate all custom topics and child agents.
3. Verify Microsoft 365 tool connections (Excel, Word, and Outlook).
4. Publish the agent.
5. Configure Microsoft Teams or Microsoft 365 channels.
6. Share the published agent with authorized users.

---

# Intended Microsoft Teams / Microsoft 365 Deployment

After publishing, the agent can be made available through:

- Microsoft Teams
- Microsoft 365 Copilot
- Microsoft Copilot Studio Web Channel


These deployment options enable end users to access the Quality Supervisor for investigation and quality management tasks.

---

# Publishing Status

 **Status:**  Not Published

The solution could not be published because the Microsoft 365 tenant requires an active billing configuration.

During the publishing step, the environment reported a billing-related restriction that prevented deployment to Microsoft Teams and other Microsoft 365 channels.

As a result:

- The agent was successfully designed and tested within Microsoft Copilot Studio.
- Custom topics, child agents, and Microsoft 365 tool integrations were validated.
- Final publishing and channel deployment could not be completed due to the billing limitation.

The solution is **functionally complete and deployment-ready**. All workflows, custom topics, specialist agents, and Microsoft 365 integrations were successfully implemented and tested in Microsoft Copilot Studio.
