# Publishing

## 1. Publish the Agent
Publish the Quality Supervisor at least once from Microsoft Copilot Studio.

Before publishing, verify that the configured child agents, mandatory topics, knowledge sources and tools are present.

## 2. Microsoft Teams
Recommended configuration sequence:
1. Open the published agent.
2. Open Channels.
3. Select Teams and Microsoft 365 Copilot.
4. Enable availability where permitted.
5. Add the channel.
6. Install the agent in Teams.

## 3. Microsoft 365 Copilot
Enable availability only where the tenant, licensing and organizational policies allow it.

Do not bypass tenant restrictions.

## 4. Tenant Limitation
If Microsoft 365 Copilot or Teams availability cannot be completed because of tenant permissions/licensing, capture the exact limitation and retain the available configuration evidence.

## 5. Interactive Experience
The published agent should support approved employee questions about:
- Open quality incidents.
- CAPA status/ownership.
- Internal policy.
- Product care/usage.
- Approved public product facts.
- Microsoft/Copilot operational guidance.

Interactive queries should not automatically initiate autonomous quality assessment unless the request requires that workflow.

## 6. Evidence
Capture publication status, channel configuration and tenant limitation evidence for final submission documentation.

Formal channel testing is intentionally deferred to the final test phase.
