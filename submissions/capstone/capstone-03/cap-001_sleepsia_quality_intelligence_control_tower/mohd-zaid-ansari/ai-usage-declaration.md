## Overview

AI tools were used to assist with the design, documentation, and implementation of the Sleepsia Product Quality & Customer Experience Intelligence Control Tower. All AI-generated outputs were reviewed, validated, and tested before implementation.

---

## AI Tools Used

| AI Tool | Purpose |
|----------|---------|
| ChatGPT | Solution design, agent instructions, custom topics, and documentation |
| Microsoft Copilot | Microsoft 365 implementation assistance |
| Microsoft Learn MCP | Official Microsoft documentation and guidance |

---

## Validation

All AI-generated content was:

- Reviewed manually
- Validated against project requirements
- Tested in Microsoft Copilot Studio
- Updated where necessary before final submission

---

## Declaration

AI was used as a development assistant only. The final solution, configuration, testing, validation, and deployment were completed and verified by the project participant.
