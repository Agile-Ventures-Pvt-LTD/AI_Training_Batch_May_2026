# AI Usage Declaration

## AI Tools Used

### Microsoft Copilot Studio
Used to:
- build the Supervisor Agent;
- configure specialist agents;
- create topics;
- configure tools/connectors;
- implement orchestration and decision workflows.

### ChatGPT
Used as a development and documentation assistant for:
- architecture planning;
- instruction drafting;
- workflow design;
- troubleshooting;
- repository documentation.

### Microsoft Learn MCP
Used through the M365 Guidance Specialist for Microsoft operational/documentation guidance.

## Human Validation
AI-generated configurations and documentation must be validated by the participant through:
- Copilot Studio configuration review;
- tool/action verification;
- topic testing;
- specialist-output testing;
- end-to-end test execution;
- MCP retrieval/fallback testing.

AI output is not treated as evidence until validated against the configured project data and actual runtime behavior.
