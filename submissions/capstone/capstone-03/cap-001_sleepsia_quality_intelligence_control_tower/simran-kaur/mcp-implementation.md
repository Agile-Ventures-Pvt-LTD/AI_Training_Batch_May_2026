# Microsoft Learn MCP Implementation

## Server
**Server name:** `Microsoft Learn MCP Serverslee`

## Purpose
Provides Microsoft operational/documentation guidance to the M365 Guidance Specialist.

## Boundary
MCP guidance:
- supports Microsoft/Copilot Studio operational questions;
- does not determine product quality;
- does not override specialist evidence;
- does not change final classification.

## Expected MCP Usage
The M365 Guidance Specialist uses the configured Microsoft Learn MCP server for Microsoft guidance and documentation retrieval.

## Failure Behavior
If MCP is unavailable:

`Microsoft guidance unavailable - manual review.`

MCP failure must not block the core quality decision.
