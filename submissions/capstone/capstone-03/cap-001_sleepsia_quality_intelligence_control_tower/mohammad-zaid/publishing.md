# CAP-001 — Publishing

## 1. Overview

The Sleepsia Product Quality & Customer Experience Intelligence Control Tower is designed to be published through Microsoft Copilot Studio and made available through supported Microsoft 365 channels.

The Quality Supervisor agent has been fully configured and the implementation has been shared with **Ankur Sir via Outlook email** for review.

However, the agent could not be published successfully because of a publishing error in the Microsoft Copilot Studio environment.

This publishing limitation does not change the configured agent architecture, topics, tools, orchestration, or autonomous workflow design.

## 4. Microsoft Teams

Microsoft Teams is the intended primary interactive channel for the Quality Supervisor.

The agent is designed to support employee requests such as:

* Open quality incidents by SKU or batch.
* CAPA status and ownership.
* Quality-policy guidance.
* Product information.
* Product care and usage information.

Because the agent could not be published successfully, live Teams channel validation could not be completed in the current environment.

---

## 5. Microsoft 365 Copilot

Microsoft 365 Copilot is an intended secondary interactive channel.

Availability depends on tenant permissions, licensing, and deployment capabilities.

Since the agent could not complete the publishing process, live Microsoft 365 Copilot validation could not be completed in the current environment.
