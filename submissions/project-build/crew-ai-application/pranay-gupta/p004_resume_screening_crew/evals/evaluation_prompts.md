### Evaluation Checks
1. Report Relevance - 
Checks if role_title and executive_summary match JD keywords.

2. Groundedness - 
Checks if strengths and evidence are present in the resume text to prevent hallucinations.

3. Recommendation Consistency - 
Checks if recommendation label matches the percentage band and if math is correct.

4. Interview Question Quality - 
Checks minimum question counts (3 tech, 2 project, 2 scenario, 2 gap) and JD keyword relevance.
