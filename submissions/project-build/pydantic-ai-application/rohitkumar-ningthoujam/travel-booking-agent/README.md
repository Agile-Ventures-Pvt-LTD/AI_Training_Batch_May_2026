## Intelligent Travel Booking Assistant

AN intelligent Travel Booking Assistant Agent using a tool-calling architecture retrieving - this agent must dynamically interact with external
systems to serve the user.
It will access a provided structured database to retrieve existing customer itineraries
and seamlessly cross-reference that data with a live weather API to provide proactive, context-aware travel advice 

## Setup

1. Create a virtual environment:
activate 
```
.venv\Scripts\activate
```

3. Install dependencies:
```
pip install -r requirements.txt

```
requirements are 
```
groq
ipykernel
python-dotenv
tiktoken
pytest
pydantic-ai
guardrails-ai
deepeval
pandas
openmeteo-requests
requests-cache 
retry-requests 
numpy 
```

4. Set up environment variables:
```
 .env.example  or .env
```

5.  `.env` with your API keys:
```
GROQ_API_KEY= your_groq_API_key
GROQ_MODEL=groq:openai/gpt-oss-120b
DB_PATH=db/travel_data.db
WEATHER_BASE_URL=https://open-meteo.com

```
6. dataset folder

## Architecture 
 
 ```
   user_input_query
          |
          |
     Guardrail (input validation for profanity/toxic languages) 
          |
          |
        Agent
          |
          |________ tool called(database_information_ weather_api_tools)     
          |
          |
    raw_outputs (generated By agent according to user data and weather information retrieved)
          |
          |
     Guardrauils( output validation )
          |
          |
     Final_fixed_ ouput     
 ```

 ## TOOLs used

 1. user_information : accepts user identifiers(e.g. email,booking_id, etc.) and retrieves  destination, travel dates, hotel details from the provided db
 2. get_weather_forcast :  Accepts a location and dates, reaching out to an external Weather API to fetch current or forecasted weather conditions.(WEATHER_BASE_URL=https://open-meteo.com)
