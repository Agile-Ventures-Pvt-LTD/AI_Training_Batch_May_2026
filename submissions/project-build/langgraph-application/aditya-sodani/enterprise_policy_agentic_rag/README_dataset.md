# Enterprise Policy Agentic RAG Sample Dataset

This is a synthetic policy corpus for **Enterprise Policy Assistant with Agentic RAG Using LangGraph**.

## Included Policy Files

```text
data/policies/
├── hr_leave_policy.md
├── travel_policy.md
├── reimbursement_policy.md
├── it_security_policy.md
└── ai_usage_policy.md
```

## Intended Use

Participants should use these files to build an Agentic RAG assistant using LangGraph.

The assistant should demonstrate:
- document loading
- chunking
- embeddings
- vector-store retrieval
- query classification
- parallel retrieval across policy domains
- context grading
- query rewriting
- clarification handling
- grounded answer generation
- answer reflection before final response

## Note

This is synthetic training data. It is not real company policy.
