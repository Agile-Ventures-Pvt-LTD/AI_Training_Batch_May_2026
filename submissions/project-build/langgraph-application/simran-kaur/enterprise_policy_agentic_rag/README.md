## Enterprise Policy Assistant with Agentic RAG Using LangGraph 

## Description

The goal of this project is to build an Agentic RAG Policy Assistant using LangGraph. The 
assistant should not behave like a simple one-step RAG chatbot. It should use a graph
based workflow that includes retrieval, grading, conditional branching, parallel retrieval, 
and grounded answer generation.

The agent takes natural language from users as input.It then decide which tool to call


The user query about the credit card management is sent to the llm. The agent then choose from various tool which are explicitly made and binded to agent. Based on the user query, appropriate tool is choosen. The result generated by tool is used by agent to generate response.

## How to Run

### 1. Clone the Repository

```bash

```

### 2. Create Virtual Environment



## PROJECT GOAL
 Product Goal 
Build an Enterprise Policy Assistant that can: 
1. Load multiple enterprise policy documents. 
2. Chunk and index policy documents. 
3. Retrieve relevant policy sections. 
4. Classify the user query. 
5. Search across multiple policy domains. 
6. Grade whether retrieved context is relevant. 
7. Rewrite the query if retrieval is weak. 
8. Ask clarification if the user’s question is ambiguous. 
9. Generate a grounded answer with citations. 
10. Review whether the final answer is supported by policy evidence. 
11. Demonstrate LangGraph workflow patterns: 
o Sequential Pattern 
o Parallelization Pattern 
o Conditional Pattern 
12. Demonstrate either: 
o LangGraph pre-built ReAct agent, or 
o Custom LangGraph ReAct-style agent.
