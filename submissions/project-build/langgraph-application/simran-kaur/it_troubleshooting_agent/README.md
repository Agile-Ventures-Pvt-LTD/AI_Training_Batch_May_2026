## Project Title
IT Troubleshooting Agent with Tool Using Workflow Using LangGraph

## Description

This project demonstrates the development of an AI-powered SQL Agent using LangGraph and SQLite.
The agent takes natural language from users as input.It then decide which tool to call.
Build an IT Troubleshooting Agent that can:
1. Understand the user’s IT issue.
2. Classify the issue type.
3. Retrieve relevant troubleshooting guidance using RAG.
4. Use tools to inspect users, devices, known incidents, tickets, and diagnostics.
5. Execute a sequential diagnostic workflow.
6. Run selected diagnostic checks in parallel where useful.
7. Branch conditionally based on issue type, severity, missing data, and tool 
results.
8. Generate a safe troubleshooting plan.
9. Recommend escalation when required.
10. Generate ticket summaries for support handoff.
11. Avoid unsafe requests for passwords, OTPs, MFA codes, or secrets.
The project uses: 

```text
-it_support.db database
-prebuilt agent
-knowledge base(For RAG)
```

The user query about the credit card management is sent to the llm. The agent then choose from various tool which are explicitly made and binded to agent. Based on the user query, appropriate tool is choosen. The result generated by tool is used by agent to generate response.

## How to Run

### 1. Clone the Repository

```bash
git clone <repository-url>
cd credit-card-agent-assignment
```

### 2. Create Virtual Environment


```bash
uv venv 
```

Activate:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
uv pip install -r requirements.txt
```


### 3. Configure Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key
```

### 4. Run the Application

```bash
python -m app
```

### 5. Run Tests


```bash
pytest tests/test_tools.py

```
