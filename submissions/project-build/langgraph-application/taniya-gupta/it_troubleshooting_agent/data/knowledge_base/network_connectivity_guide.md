# Network Connectivity Troubleshooting Guide
**Document ID:** IT-KB-NET-001
**Owner:** Network Support
**Effective Date:** 2026-01-01

## 1. Common Symptoms
Employees may report no internet, slow internet, application connectivity errors, DNS failure, Wi-Fi disconnects, or inability to access internal systems.

## 2. First-Level Checks
Check:
- User is connected to Wi-Fi or wired network.
- Other websites are accessible.
- Internal systems are affected or all systems are affected.
- VPN is required for the target system.
- Known network incidents.
- DNS resolution if technical diagnostics are available.

## 3. No Internet
If there is no internet:
1. Ask user to reconnect Wi-Fi.
2. Ask user to test another website.
3. Restart network adapter or device.
4. Ask user to test mobile hotspot.
5. Escalate to Network Support if issue affects multiple users.

## 4. Internal Application Not Accessible
If public internet works but internal app fails:
- Confirm whether VPN is connected.
- Check known incidents for the application.
- Check whether the app requires corporate network access.
- Escalate to Application Support if only one application fails.

## 5. Slow Internet
If internet is slow:
- Ask user to test speed on another network.
- Check if issue occurs on VPN only.
- Ask user to close bandwidth-heavy applications.
- Escalate if multiple users in same location report the issue.

## 6. Escalation Criteria
Escalate to Network Support when:
- Multiple users are affected.
- Known network incident exists.
- VPN gateway or DNS issue is suspected.
- User cannot access internal systems from multiple networks.
