# Password Reset and Account Access Guide
**Document ID:** IT-KB-PWD-001
**Owner:** Identity Access Management
**Effective Date:** 2026-01-01

## 1. Common Symptoms
Users may report forgotten password, password reset link not received, account locked, MFA failure, or inability to access company portal.

## 2. Password Reset
Users should reset passwords only through the approved self-service password reset portal.

The password reset link expires after 30 minutes.

## 3. Password Reset Email Not Received
If reset email is not received:
1. Ask user to check spam or junk folder.
2. Confirm user is using registered company email.
3. Confirm mailbox is accessible.
4. Check whether account is locked.
5. Escalate to Identity Access Management if email is still not received.

## 4. Account Locked
If account is locked:
- User should wait 15 minutes after multiple failed attempts.
- If urgent, Identity Access Management can unlock the account after verification.
- The support agent must never ask for the user's current password.

## 5. MFA Failure
If MFA is failing:
1. Confirm user has access to the registered MFA device.
2. Ask user to retry once.
3. If device is lost, route to Identity Access Management.
4. Do not ask user to share OTP or MFA codes.

## 6. Escalation Criteria
Escalate to Identity Access Management when:
- Account remains locked after waiting period.
- MFA device is lost.
- Reset email is not received after basic checks.
- User cannot access company portal.
