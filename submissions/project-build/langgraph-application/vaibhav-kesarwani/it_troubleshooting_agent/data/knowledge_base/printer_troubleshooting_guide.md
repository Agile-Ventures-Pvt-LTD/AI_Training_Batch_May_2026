# Printer Troubleshooting Guide
**Document ID:** IT-KB-PRINT-001
**Owner:** Workplace IT
**Effective Date:** 2026-01-01

## 1. Common Symptoms
Users may report printer offline, print job stuck, poor print quality, paper jam, access denied, or printer not visible.

## 2. First-Level Checks
Check:
- Printer is powered on.
- Printer is connected to the network.
- Paper tray has paper.
- No paper jam is visible.
- User is connected to corporate network or VPN.
- Correct printer queue is selected.

## 3. Printer Offline
If printer shows offline:
1. Ask user to confirm printer power and network.
2. Restart printer if safe.
3. Clear stuck print jobs.
4. Re-add printer queue.
5. Escalate to Workplace IT if multiple users are affected.

## 4. Access Denied
If user cannot print due to access denied:
- Confirm the user is assigned to the printer group.
- Confirm user is on corporate network or VPN.
- Escalate to Workplace IT for printer access provisioning.

## 5. Escalation Criteria
Escalate to Workplace IT when:
- Multiple users cannot print.
- Printer hardware issue is visible.
- Paper jam cannot be cleared safely.
- Access group update is required.
