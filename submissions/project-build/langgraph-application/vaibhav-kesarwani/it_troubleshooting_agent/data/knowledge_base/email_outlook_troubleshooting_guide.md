# Outlook and Email Troubleshooting Guide
**Document ID:** IT-KB-EMAIL-001
**Owner:** Messaging Support
**Effective Date:** 2026-01-01

## 1. Common Symptoms
Employees may report Outlook not syncing, email stuck in outbox, missing emails, repeated password prompts, calendar not updating, or mobile email issues.

## 2. First-Level Checks
Check:
- Internet connectivity.
- Outlook client is open and not in offline mode.
- Mailbox quota is not exceeded.
- Microsoft 365 service health is normal.
- User account is not locked.
- Device date and time are correct.

## 3. Outlook Not Syncing
If Outlook is not syncing:
1. Confirm whether webmail works.
2. Restart Outlook.
3. Check offline mode.
4. Check mailbox quota.
5. Create a new Outlook profile if issue persists.
6. Escalate to Messaging Support if webmail also fails.

## 4. Email Stuck in Outbox
If email is stuck in outbox:
- Check attachment size.
- Company maximum attachment size is 25 MB.
- Ask user to remove large attachments and use approved file sharing.
- Restart Outlook.
- Check mailbox connectivity.

## 5. Repeated Password Prompt
If Outlook repeatedly asks for password:
1. Confirm account is not locked.
2. Check whether password was recently changed.
3. Clear cached credentials.
4. Re-authenticate with MFA.
5. Escalate to Identity Access Management if authentication fails.

## 6. Escalation Criteria
Escalate to Messaging Support when:
- Webmail is also unavailable.
- Multiple users from same region report email outage.
- Mailbox corruption is suspected.
- Service health shows degradation.

Escalate to Identity Access Management when:
- Authentication failure persists.
- Account lock is confirmed.
- MFA is failing.

## 7. Security Guidance
Do not ask users for their password or MFA code.
