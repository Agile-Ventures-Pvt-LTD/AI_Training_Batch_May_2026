# Laptop Performance Troubleshooting Guide
**Document ID:** IT-KB-LAPTOP-001
**Owner:** Endpoint Support
**Effective Date:** 2026-01-01

## 1. Common Symptoms
Employees may report slow startup, high CPU, high memory usage, freezing, overheating, poor battery performance, or applications taking too long to open.

## 2. First-Level Checks
Check:
- Available disk space.
- CPU usage.
- Memory usage.
- Startup applications.
- Pending OS updates.
- Antivirus scan status.
- Recently installed applications.
- Device age and hardware configuration.

## 3. Slow Startup
If laptop is slow after startup:
1. Check startup applications.
2. Confirm disk free space is above 15%.
3. Check whether OS updates are pending.
4. Restart the laptop.
5. Run endpoint health check.
6. Escalate to Endpoint Support if slowness continues after cleanup.

## 4. High CPU or Memory
If CPU or memory is consistently high:
- Identify top resource-consuming processes.
- Close unnecessary applications.
- Check for browser tabs consuming excessive memory.
- Run malware scan if suspicious process is detected.
- Escalate if usage remains above 85% after restart.

## 5. Low Disk Space
If free disk space is below 10%:
- Ask user to remove temporary files.
- Move large non-confidential files to approved storage.
- Do not move company confidential data to personal storage.
- Escalate if disk cleanup fails or disk health warning appears.

## 6. Escalation Criteria
Escalate to Endpoint Support when:
- CPU or memory remains above 85% after restart.
- Disk health warning is present.
- Device is overheating frequently.
- Malware alert appears.
- Device compliance check fails.
