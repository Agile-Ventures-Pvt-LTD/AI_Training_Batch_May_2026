# Dataset Notes

## Overview

The solution uses trainer-provided datasets to simulate campaign readiness governance workflows.

Datasets were consumed through Copilot Studio tools and Excel Online connectors.

---

## Campaign Requests

Primary intake dataset in `P2-005_Marketing_Campaign_Readiness_Lab_Data.xlsx` containing:

- Campaign ID
- Campaign Name
- Product
- Objective
- Launch Date
- Budget Information
- Geography
- Channel Information
- Sensitivity Classification

Used by:

- Intake & Validation Topic
- Budget Specialist
- Brand Specialist
- Channel Specialist
