# AI Usage Declaration

## Project

Supply Continuity Disruption Response Agent

---

# Purpose of AI Usage

Artificial Intelligence is used to coordinate and automate disruption assessment workflows within Microsoft Copilot Studio.

The solution uses AI orchestration to:

- Interpret disruption records
- Coordinate specialist execution
- Consolidate specialist findings
- Apply governance policies
- Route approval decisions
- Generate reports and stakeholder communications

AI is used as a decision-support mechanism and not as an autonomous decision authority.

---

# Human Oversight

The system includes multiple governance controls:

- Validation checkpoints
- Policy precedence rules
- Approval routing
- Reassessment limits
- Escalation paths
- Manual review capability

Human approval remains required where defined by business policy.

---

# AI Limitations

The system is explicitly restricted from:

- Approving suppliers
- Approving expenditures
- Creating purchase orders
- Committing inventory
- Modifying contracts
- Promising delivery dates
- Overriding business policies

---

# Data Sources

AI outputs are based on:

- Disruption Request Table
- Inventory Table
- SKU Master Table
- Supplier Table
- Alternate Supplier Table
- Customer Orders Table
- Recovery Rules Table
- Policy Knowledge Base

The system does not intentionally generate findings unsupported by retrieved data.

---

# Responsible AI Practices

The implementation follows the following principles:

- Transparency
- Traceability
- Explainability
- Human Accountability
- Policy Compliance
- Evidence-Based Decision Making

All recommendations must be traceable to workbook data, specialist findings, or policy rules.

---

# Use of Generative AI During Development

Generative AI tools were used to assist with:

- Workflow design
- Topic design
- Prompt engineering
- Documentation drafting
- Test case generation

Final implementation, validation, testing, and deployment decisions were performed by the project team.

---

This solution provides operational recommendations and workflow automation support.

Final business decisions remain the responsibility of authorized personnel and business stakeholders.
