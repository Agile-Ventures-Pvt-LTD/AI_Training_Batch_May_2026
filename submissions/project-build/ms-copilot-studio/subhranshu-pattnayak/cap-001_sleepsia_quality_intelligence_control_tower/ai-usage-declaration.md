# AI Usage Declaration

## Overview

This project was developed using Microsoft Copilot Studio as the primary platform for agent orchestration, workflow design, topic implementation, and tool integration.

Artificial Intelligence was used as a development aid during the project lifecycle.

---

## AI Usage Areas

AI assistance was used for:

- Requirement interpretation
- Workflow design discussions
- Agent instruction drafting
- Topic design support
- Documentation preparation
- Troubleshooting guidance
- Iterative refinement of prompts and agent instructions

---

## Human Contributions

All final implementation decisions were made manually.

Project activities completed by the author include:

- Solution design
- Architecture planning
- Agent configuration
- Topic creation
- Tool configuration
- Knowledge source configuration
- Workbook preparation
- Testing execution
- Validation of outputs
- Documentation review and finalization

---

## Verification

All configurations, workflows, prompts, topics, tools, and documentation were reviewed and adjusted as necessary before inclusion in the final submission.

AI-generated suggestions were treated as assistance and not accepted automatically without review.

---

## Declaration

AI tools were used to support development and documentation activities; however, responsibility for the final design, implementation, testing, and submitted deliverables remains with the author.
