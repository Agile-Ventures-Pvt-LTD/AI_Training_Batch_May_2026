# P2-005: Autonomous Marketing Campaign Launch Readiness & Governance System

Welcome to the official submission repository for the **Autonomous Marketing Campaign Launch Readiness & Governance System** built for **NovaSphere Technologies Pvt. Ltd.** using Microsoft Copilot Studio.

This system is an autonomous multi-agent solution designed to verify whether marketing campaigns are structurally, financially, and legally ready for deployment. It replaces a manual review process that involved multiple isolated teams with an integrated, deterministic governance workflow.
