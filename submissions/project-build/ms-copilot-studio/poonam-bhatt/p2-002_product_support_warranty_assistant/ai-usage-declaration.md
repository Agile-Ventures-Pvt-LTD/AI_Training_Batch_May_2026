# AI Usage Declaration

# P2-002 Product Support and Warranty Assistant

---

# 1. Overview

This document explains the usage of Artificial Intelligence during the development of the NovaCare Product Support and Warranty Assistant.

AI was used as a development assistance tool to improve productivity, generate ideas, assist documentation, and support solution design.

All final decisions, configurations, testing, and validations were performed by the project team.

---

# 2. AI Tools Used

## Microsoft Copilot Studio

Purpose:

Microsoft Copilot Studio was used to build the conversational AI agent.

Usage:

- Creating the customer support agent
- Designing custom topics
- Configuring conversation flows
- Managing variables
- Connecting knowledge sources
- Testing agent responses

---

## Generative AI Assistance

Generative AI tools were used for:

- Brainstorming solution architecture
- Improving documentation quality
- Reviewing conversation designs
- Generating test scenarios
- Identifying possible edge cases

---

# 3. AI-Assisted Development Areas

## 3.1 Agent Design Assistance

AI assistance was used for:

- Structuring the agent workflow
- Defining topic responsibilities
- Designing conversation paths
- Identifying required information collection steps

Human review was performed to ensure alignment with the P2-002 PRD requirements.

---

## 3.2 Documentation Assistance

AI assistance was used for preparing:

- README documentation
- Solution summary
- Agent design documentation
- Knowledge source documentation
- Custom topic documentation
- Test reports
- Known limitations documentation

All generated documentation was reviewed and modified based on the actual implementation.

---

## 3.3 Testing Assistance

AI assistance was used to create:

- Functional test scenarios
- Edge cases
- Safety scenarios
- Warranty assessment scenarios

Final testing was manually performed on the implemented agent.

---

# 4. AI Knowledge Usage

The assistant itself uses AI capabilities for:

- Understanding customer queries
- Identifying user intent
- Generating conversational responses
- Providing grounded responses from connected knowledge sources

The agent does not rely only on general AI knowledge.

Responses are controlled using:

- NovaCare warranty policy
- Product support scope
- Product safety and escalation policy

---

# 5. Human Validation and Control

Human review was performed for:

- Agent instructions
- Topic design
- Conversation flow
- Knowledge source selection
- Safety handling
- Warranty logic
- Test validation

The project team verified that the assistant follows the required business rules and PRD guidelines.

---

# 6. Responsible AI Practices

The solution follows responsible AI principles:

## Accuracy

The agent uses approved knowledge sources to reduce unsupported responses.

---

## Safety

The agent prioritizes customer safety and stops troubleshooting when safety risks are detected.

---

## Transparency

The agent communicates limitations and provides preliminary assessments instead of making unauthorized decisions.

---

## Privacy

The agent does not request unnecessary personal information.

Sensitive information such as full serial numbers should not be stored in screenshots or documentation.

---

# 7. AI Limitations Considered

During development, the following AI limitations were considered:

- Possibility of incorrect interpretation of user queries
- Need for grounded knowledge sources
- Requirement for human review in complex cases
- Dependency on accurate customer-provided information

Controls were implemented to reduce these risks.

---

# 8. Final Declaration

AI was used as an assistance tool during the development process.

The final Product Support and Warranty Assistant was designed, configured, tested, and validated according to the P2-002 requirements.

AI supports the solution, but business decisions, safety decisions, and warranty decisions remain controlled by defined policies and human review processes.
