# AI Usage Declaration

## P2-004 Autonomous Multi-Agent BC/DR Readiness System

## Overview
ChatGPT was used as an assistance tool for analysing the project workflow, understanding requirements, designing the multi-agent architecture, preparing Copilot Studio instructions, and creating project documentation.

## AI Usage Areas

- Analysed the complete BC/DR workflow
- Assisted in designing Supervisor Agent and Specialist Agent responsibilities.
- Helped create agent instructions, orchestration flow, and decision logic.
- Assisted in understanding Microsoft Copilot Studio capabilities and MCP integration.
- Supported documentation creation including architecture, implementation notes, and test documentation.
- Helped review integration flow between agents, Excel, Word, Outlook, and Microsoft Learn MCP Server.

## Responsible AI Practices

- All final configurations and implementations were reviewed and validated by the participant.
- AI was used for guidance and documentation support, not for replacing implementation decisions.
- No fabricated screenshots, MCP evidence, or test results were generated.
- MCP findings were based on actual Microsoft Learn retrieval and validation.
- Synthetic data was used for testing purposes.
