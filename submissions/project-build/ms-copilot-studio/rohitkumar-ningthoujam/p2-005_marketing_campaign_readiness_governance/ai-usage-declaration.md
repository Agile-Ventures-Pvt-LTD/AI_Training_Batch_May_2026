# AI Usage Declaration

## Declaration

This project was implemented using **Microsoft Copilot Studio** as the primary development platform. **ChatGPT** was used as an AI-assisted development tool to support solution design, documentation, and implementation.

## AI Assistance

The following activities were assisted by ChatGPT:

- Interpreting the Project Requirements Document (PRD)
- Designing the supervisor and specialist agent architecture
- Drafting agent instructions
- Designing custom topic workflows
- Defining orchestration patterns
- Designing tool configurations and integration logic
- Preparing project documentation
- Creating evaluation test cases and reports
- Reviewing and refining implementation

## Microsoft Copilot Studio

The following activities were completed in Microsoft Copilot Studio:

- Creating the supervisor agent
- Creating specialist child agents
- Configuring tools and Microsoft 365 connectors
- Building custom topics and workflow logic
- Uploading knowledge sources
- Configuring agent instructions
- Testing and debugging workflows
- Publishing and validating the solution

## Human Contribution

All AI-generated content was reviewed, validated, and adapted before implementation. The final solution, configuration, testing, and submission were completed by the project author.

## Acknowledgement

This submission represents my own implementation. AI tools were used to improve productivity and documentation quality while ensuring that the final solution meets the project requirements.
