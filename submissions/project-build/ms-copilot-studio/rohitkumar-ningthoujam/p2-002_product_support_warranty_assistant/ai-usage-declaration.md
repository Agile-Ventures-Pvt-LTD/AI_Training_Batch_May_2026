# AI Usage Declaration

## AI Usage

Microsoft Copilot Studio AI was used to build the Product Support and Warranty Assistant.

Used for:
- Topic design
- Conversation flow creation
- Documentation support
- Response generation

## Human Review

All AI-generated content and workflows were reviewed and configured based on project requirements.

## Responsible AI

- Uses grounded knowledge sources.
- Avoids unsupported claims.
- Escalates safety and warranty cases to humans.
