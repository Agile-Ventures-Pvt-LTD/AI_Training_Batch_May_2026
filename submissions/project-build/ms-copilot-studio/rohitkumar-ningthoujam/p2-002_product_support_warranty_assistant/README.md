# P2-002 Product Support and Warranty Assistant

## Project Overview

This project implements a Microsoft Copilot Studio chatbot for product support troubleshooting, safety triage, and preliminary warranty assessment.

## Project Name

Product Support and Warranty Assistant

## Platform

Microsoft Copilot Studio

## Main Features

- Guided product troubleshooting
- Product safety assessment
- Warranty preliminary assessment
- Support case summary generation
- Escalation handling

## Supported Products

- Lenovo ThinkPad E14 Gen 5 Laptop
- HP LaserJet Pro MFP M428-M429 Printer

## Knowledge Sources

- Product Support Scope
- Product Safety and Escalation Policy
- Manufacturer support sources
