# P2-006 — AI Usage Declaration

## AI Tools Used

The project used both Microsoft Copilot and ChatGPT as AI-assisted development tools.

### Microsoft Copilot

Microsoft Copilot was used to support:

- Agent instruction development.
- Topic flow design.
- Topic configuration guidance.
- Orchestration logic development.
- Review and refinement of agent behaviour.

### ChatGPT

ChatGPT was used to support:

- Agent instruction development.
- Topic flow design.
- Orchestration-flow planning.
- Documentation preparation.
- Project documentation structuring.
- Test-case documentation preparation.

## Scope of AI Assistance

AI assistance was primarily used for:

1. Designing agent instructions.
2. Designing custom-topic flows.
3. Structuring orchestration logic.
4. Preparing and organising project documentation.

## Human Responsibility

The project team remained responsible for:

- Final agent configuration.
- Final topic implementation.
- Business-rule implementation.
- Tool configuration.
- Validation of the solution.
- Test execution.
- Review of generated documentation.
- Final submission.

AI-generated suggestions were reviewed and adapted to the project requirements before being used.
