# Project Overview

The Autonomous Sales Lead Qualification Agent is an event-driven Microsoft Copilot Studio solution that automatically processes incoming Outlook emails related to sales inquiries.

The agent identifies valid sales opportunities, extracts business information, checks for duplicate records, applies qualification rules, assigns an appropriate sales owner, updates the operational Excel workbook, generates Microsoft Word qualification reports when required, and sends the appropriate Outlook communications without manual intervention.

The solution is implemented completely within Microsoft Copilot Studio using Generative Orchestration and Microsoft 365 connector tools.

---

# Business Objective

Automate the complete first-level sales qualification process by:

- Monitoring Outlook for qualifying sales emails
- Extracting lead information
- Validating mandatory fields
- Reading operational reference data
- Detecting duplicate opportunities
- Calculating qualification score
- Assigning lead classification
- Assigning sales owner
- Creating qualification reports
- Sending acknowledgement and notification emails
