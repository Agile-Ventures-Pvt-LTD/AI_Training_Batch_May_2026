# Chatbot Screenshots Guide

This directory contains the verification screenshots demonstrating the configuration and testing of the **NovaRetail Support and Warranty Assistant** in Microsoft Copilot Studio.

---

## Required Screenshots

To satisfy Section 16.4 of the PRD, please capture and save the following screenshots into this directory using the exact file names listed below:

| File Name | Description / What to capture |
| :--- | :--- |
| **`agent-overview.png`** | The Copilot Studio main overview dashboard displaying the bot's identity and setup. |
| **`agent-instructions.png`** | The settings panel showing the complete Agent System Instructions configured in the bot. |
| **`knowledge-sources.png`** | The knowledge base tab showing the 7 configured knowledge sources (PDFs, Websites, MDs). |
| **`troubleshooting-topic.png`** | The conversation canvas showing trigger phrases and the start of Custom Topic 1. |
| **`warranty-topic.png`** | The conversation canvas showing triggers and variables of Custom Topic 2. |
| **`safety-subtopic.png`** | The canvas flow of the reusable Product Safety Assessment subtopic. |
| **`case-summary-subtopic.png`** | The canvas showing how the reusable Support Case Summary subtopic is called and formatted. |
| **`conditional-branches.png`** | A view of nested conditional branching and redirects (such as the cross-topic redirection). |
| **`grounded-laptop-answer.png`** | A chat test showing a successful grounded response retrieved from the Lenovo User Guide. |
| **`grounded-printer-answer.png`**| A chat test showing a successful grounded response retrieved from the HP User Guide. |
| **`safety-escalation.png`** | A chat test showing immediate stopping of troubleshooting and Level 4 escalation on a hazard query. |
| **`published-agent.png`** | The Copilot Studio publishing page showing the bot successfully published and shared. |

---

## Important Rules

> [!WARNING]
> - **Exclusion of Sensitive Data:** Ensure that none of the screenshots expose passwords, personal API tokens, security secrets, confidential customer information, full database serial numbers, or sensitive tenant keys.
> - **Readable Resolution:** Save the screenshots in standard `.png` format with clean readability for evaluation.
