# AI Usage Declaration

## Project Name

**IIMA HR Policy Assistant**


## 1. AI Tools Used

The following AI tools and technologies were used during the development of this project:

| AI Tool | Usage |
|---------|-------|
| Microsoft Copilot Studio | Used to build, configure, test, and publish the HR Policy Assistant chatbot. |
| Generative AI capabilities in Copilot Studio | Used for natural language understanding and generating responses based on user queries. |
| Retrieval-Augmented Generation (RAG) | Used to retrieve relevant information from configured knowledge sources and provide grounded responses. |
| AI Assistance Tools | Used for documentation support, test case preparation, and improving solution design. |

---

# 2. How AI Assisted the Development

AI assisted the development process in the following areas:

## Solution Development

- Helped design the conversational flow for the HR Policy Assistant.
- Assisted in identifying suitable knowledge sources for HR-related queries.
- Supported the creation of custom topics such as **Leave Request Advisor**.

---

## Knowledge-Based Responses

- AI capabilities were used to retrieve information from:
  - HR Policy Addendum
  - IIMA HR Policy PDF
  - Rochester HR Website reference

- Generated responses were based on retrieved information to reduce unsupported answers.

---

## Topic Development

AI assistance was used to design and improve conversation flows for:

### Leave Request Advisor

AI helped structure:

- User intent understanding.
- Leave-related questions.
- Follow-up conversation handling.

---

## Testing and Documentation

AI was used to assist with:

- Creating test scenarios.
- Improving test coverage.
- Preparing project documentation.
- Organizing README and test reports.

---

# 3. Outputs Manually Validated

All AI-generated outputs were reviewed manually before acceptance.

The following areas were validated:

## Knowledge Source Responses

Checked that:

- Responses matched the provided HR documents.
- Information was relevant to employee queries.
- No incorrect information or hallucinated policies were generated.

---

## Custom Topic Responses

Validated:

- Correct topic triggering.
- Conversation flow execution.
- User input handling.
- Expected responses for different scenarios.

---

## Documentation Outputs

Manually reviewed:

- README.md
- TEST_REPORT.md
- AI_USAGE_DECLARATION.md

to ensure they accurately represented the implemented solution.

---

# 4. Corrections Made to AI-Generated Suggestions

During development, the following corrections were made:

## Response Improvements

- Updated agent instructions to ensure responses remain within available knowledge sources.
- Improved response accuracy by refining prompts and instructions.

---

## Topic Flow Corrections

- Modified topic trigger phrases.
- Adjusted conversation steps.
- Improved handling of incomplete or unclear user requests.

---

## Testing Improvements

- Added additional normal, negative, and adversarial test scenarios.
- Identified blocked test cases related to the missing Workplace Concern topic.
- Retested updated conversation flows.

---

## Documentation Corrections

AI-generated documentation suggestions were reviewed and modified to:

- Match the actual project implementation.
- Remove unsupported assumptions.
- Clearly mention completed and pending features.

---

# 5. Human Validation Statement

Although AI tools were used during development, all important outputs were manually reviewed and verified.

Final decisions regarding:

- Agent configuration
- Knowledge sources
- Custom topics
- Test results
- Documentation

were performed through human validation.

---

# 6. Summary

AI tools improved development efficiency by supporting chatbot design.
However, all AI-generated suggestions were reviewed, corrected where required, and validated to ensure accuracy, reliability, and alignment with project requirements.
