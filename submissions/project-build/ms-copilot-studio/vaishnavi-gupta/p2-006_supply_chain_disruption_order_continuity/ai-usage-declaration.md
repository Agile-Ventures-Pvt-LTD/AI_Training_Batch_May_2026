# AI Usage Declaration

## AI Assistance Statement

This project was developed by **Vaishnavi Gupta** using **Microsoft Copilot Studio** as the primary implementation platform.

During the project, **ChatGPT (OpenAI)** was used as a supplementary learning and productivity tool for:

- Understanding the business scenario and requirements
- Designing agent instructions and orchestration logic
- Refining documentation and project artifacts
- Generating implementation ideas and test scenarios
- Reviewing and improving written content

All solution design decisions, implementation, testing, validation, screenshots, and final submissions were completed and verified by the author.

No AI-generated content was accepted without review, and AI was not used to fabricate approvals, test results, screenshots, system outputs, or operational evidence.
