# AI Usage Declaration

## Purpose

Artificial Intelligence (AI) was used as a development aid during the design and implementation of this project. The primary AI tool used was **ChatGPT by OpenAI**, which assisted in drafting documentation, refining agent instructions, designing the multi-agent workflow, preparing project artifacts, and improving the overall structure of the solution.

## Scope of AI Usage

AI assistance was used for:
- Creating and refining project documentation (README, design documents, summaries, and supporting markdown files).
- Drafting agent descriptions and instructions.
- Designing the multi-agent workflow and orchestration logic.
- Suggesting testing scenarios and implementation approaches.
- Improving the clarity and consistency of technical content.

## Developer Responsibility

All AI-generated content was reviewed, validated, and adapted to meet the project requirements. The final implementation, configuration, testing, and submission were completed by the project developer. Any AI-generated suggestions were verified before being incorporated into the solution.

## AI Tools Used

- **ChatGPT (OpenAI)** – Documentation support, workflow design, agent instruction generation, and implementation guidance.
- **Microsoft Copilot Studio** – Development platform used to build the autonomous multi-agent BC/DR readiness assessment system.
