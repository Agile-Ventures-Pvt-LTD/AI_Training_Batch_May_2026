# AI Usage Declaration

## AI Tools Used

- ChatGPT (OpenAI)

## How AI Assisted the Development

AI was used as a development assistant to:

- Draft agent instructions for Microsoft Copilot Studio.
- Suggest conversation starters and trigger phrases.
- Help design the custom topic workflows.
- Generate sample conversation flows and conditional logic.
- Help in preparing project documentation.


## Manual Validation Performed

All AI-generated content was manually reviewed and verified against the project requirements before implementation.

The following were manually validated:

- Agent instructions
- Knowledge source configuration
- Conversation flows
- Variables and conditions
- Trigger phrases
- Test cases
- Chatbot responses

## Corrections Made

Minor modifications were made to AI-generated suggestions to ensure they aligned with the project requirements and the NovaWorks HR Policy Addendum. Conversation flows, branching logic, and chatbot responses were refined and tested manually within Microsoft Copilot Studio before final submission.

---

**Declaration:**  
AI was used solely to assist with drafting, designing, and improving the solution. The final implementation, validation, testing, and submission were completed manually.
