# AI Usage Declaration

## Project
P2-006 — Autonomous Supply Chain Disruption & Order Continuity Response System

## AI usage
AI assistance was used for:
- Understanding the business scenario and PRD
- Designing agent instructions
- Designing child-agent responsibilities
- Designing custom topic logic
- Designing variables and structured handoffs
- Debugging Copilot Studio configuration
- Generating test ideas
- Improving technical documentation

## Human responsibility
The participant remains responsible for:
- Implementing the solution in Microsoft Copilot Studio
- Configuring connectors and permissions
- Verifying all business rules
- Testing actual orchestration
- Capturing screenshots and execution evidence
- Validating actual outputs
- Explaining all orchestration patterns

## Prohibited fabrication
AI assistance must not be used to fabricate:
- supplier approval
- customer agreement
- purchase-order placement
- human approval
- test evidence
- screenshots
- emails sent
- tool execution results

## Evidence principle
All claims about execution, testing, screenshots, report creation, Excel updates, and Outlook notifications must be supported by actual system evidence.

## Business-rule principle
The supplied Supply Continuity Policy and explicit deterministic rules take precedence over generic language-model judgment.
