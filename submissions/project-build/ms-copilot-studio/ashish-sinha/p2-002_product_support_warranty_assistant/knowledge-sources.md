# Knowledge Sources

## Project

Product Support & Warranty Assistant

## Scope

This project currently supports only the **Lenovo ThinkPad E14 Gen 5** laptop.

The following knowledge sources are used to ground responses for troubleshooting, safety guidance, and preliminary warranty assessment.

---

High

24 July 2026

# Retrieval Strategy

The assistant should retrieve information using the following priority order:

1. Lenovo Safety Information
2. Lenovo Support Website
3. Lenovo User Guide
4. NovaCare Warranty Policy

If multiple sources contain relevant information, safety guidance takes precedence over troubleshooting guidance.

---

# Knowledge Boundaries

The assistant must only use information contained in the approved knowledge sources.

The assistant must not:

- Generate unsupported troubleshooting steps.
- Invent warranty policies.
- Guess technical specifications.
- Approve warranty claims.
- Reject warranty claims.
- Recommend unsafe procedures.
- Provide unofficial repair instructions.

If the requested information is unavailable, the assistant should recommend contacting an authorized Lenovo or NovaRetail support representative.

---

# Knowledge Maintenance

Knowledge sources should be reviewed periodically to ensure that:

- Product documentation remains current.
- Warranty policies are up to date.
- Safety guidance reflects the latest manufacturer recommendations.
- Unsupported or obsolete information is removed.
