# Opening Instructions

Once published:

1. Open the published chatbot URL in a supported web browser.
2. Start a new conversation.
3. Enter a supported query such as:
   - "My laptop won't turn on."
   - "Check my warranty."
   - "Battery is draining quickly."
4. Follow the guided conversation.
5. Complete troubleshooting or warranty assessment.
6. Review the generated support summary.

---

# Current Limitations

The published chatbot currently supports only:

- Lenovo ThinkPad E14 Gen 5

The chatbot currently does not support:

- HP Printers
- Other Lenovo laptop models
- Live warranty lookup
- Repair status tracking
- Service ticket creation
- Remote diagnostics
- Inventory availability
- Final warranty decisions
- Emergency service integration

---

# Verification Checklist

Before publication, verify that:

- Product validation works correctly.
- Product Safety Assessment subtopic executes before troubleshooting.
- Warranty Eligibility Assessment functions correctly.
- Support Case Summary is generated successfully.
- Generative Answers use only approved knowledge sources.
- Unsupported products are handled appropriately.
- Safety-critical cases are escalated correctly.
- Conversation cancellation behaves as expected.
