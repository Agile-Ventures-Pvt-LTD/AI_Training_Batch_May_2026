# AI usage declaration

## NovaSphere supply continuity autonomous multi-agent system

## Purpose

This document declares the use of artificial intelligence tools during the design, development, documentation, and implementation of the NovaSphere Supply Continuity Autonomous Multi-Agent System.

AI tools were used as development assistants to improve architecture design, documentation quality, prompt engineering, workflow planning, and implementation efficiency.

All final design decisions, architecture validation, workflow configuration, testing, and project integration were reviewed and implemented by the project author.

## AI tools used

| AI tool                     | Purpose of use                                                                                                                                                                                  |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ChatGPT (OpenAI)            | Architecture design, multi-agent workflow design, prompt engineering, documentation drafting, technical writing, orchestration planning, decision-rule formulation, and implementation guidance |
| Google Gemini               | Alternative architecture exploration, documentation refinement, validation of workflow concepts, and technical writing assistance                                                               |
| Microsoft Copilot Studio AI | Child-agent instruction refinement, topic creation assistance, orchestration guidance, Copilot Studio implementation support, and conversational workflow optimization                          |

## Scope of AI assistance

AI tools were used for the following activities:

* multi-agent architecture design,
* Supervisor Agent orchestration planning,
* specialist child-agent instruction drafting,
* deterministic decision-rule development,
* approval workflow design,
* Power Automate integration planning,
* technical documentation creation,
* README and architecture documentation,
* testing documentation,
* workflow refinement,
* implementation planning.

## Human responsibility

The project author was responsible for:

* defining the project requirements,
* interpreting the PRD,
* designing the final architecture,
* configuring Copilot Studio,
* implementing child agents,
* creating custom topics,
* integrating Power Automate,
* validating decision rules,
* testing the end-to-end workflow,
* reviewing all generated content,
* ensuring PRD compliance.

All AI-generated content was reviewed, modified where necessary, and integrated into the final implementation.

## AI-generated artifacts

The following artifacts were prepared with AI assistance:

* system architecture documentation,
* Supervisor Agent design,
* specialist-agent design,
* orchestration patterns,
* decision rules,
* autonomous trigger design,
* custom-topic documentation,
* reporting documentation,
* testing documentation,
* project README,
* implementation documentation.

## Compliance statement

AI tools were used to support software engineering, documentation, and system design activities.

The final project implementation, configuration, validation, and submission reflect the author's review, integration, and responsibility for the resulting system.
