# AI Usage Declaration

## Project
**NovaHR Assist – HR Employee Assistance RAG Chatbot**

---

## AI Tools Used

The following AI tools were used during the development of this project:

- **ChatGPT (OpenAI)** – Used for drafting prompts, refining chatbot instructions, designing conversation flows, generating trigger phrases.
- **Microsoft Copilot Studio AI Features** – Used to generate initial topic structures, configure knowledge sources, and assist in developing conversational workflows.

---

## How AI Assisted the Development

Generative AI was used as a development assistant throughout the project. Specifically, AI assisted with the following activities:

- Drafting the system instructions for the NovaHR Assist chatbot.
- Creating and refining trigger phrases for each custom topic.
- Improving chatbot responses for clarity, professionalism, and empathy.
- Suggesting conditional logic for policy-based conversations.
- Assisting with Microsoft Copilot Studio configuration and troubleshooting.
- Preparing project documentation, including the solution summary, test report, and deployment documentation.

---

## Outputs Manually Validated

All AI-generated content was manually reviewed and validated before being incorporated into the final chatbot.

The following outputs were verified against the official project requirements and configured knowledge sources:

- System prompt and chatbot instructions.
- Knowledge source descriptions.
- Trigger descriptions.
- Conversation flows for all custom topics.
- Prompt Node instructions.
- Leave policy logic.
- Workplace concern escalation logic.
- Employment verification request workflow.
- Test cases and expected results.
- Project documentation.
---

## Corrections Made to AI-Generated Suggestions

Several AI-generated suggestions were modified before implementation to ensure compliance with the project requirements and HR policies.

Corrections included:

- Updating chatbot instructions to strictly follow the NovaWorks HR Policy Addendum.
- Replacing rigid question-by-question conversations with Prompt Node–based information extraction where appropriate.
- Ensuring that leave requests provide policy guidance only and never indicate approval.
- Updating employment verification workflows to generate only a request summary instead of an official employment verification letter.
- Removing unsupported HR policy statements and ensuring all responses were grounded in the configured knowledge sources.
- Refining trigger phrases and topic logic to improve user experience and conversation accuracy.
- Validating all generated test cases against the mandatory testing scenarios defined in the project requirements.
