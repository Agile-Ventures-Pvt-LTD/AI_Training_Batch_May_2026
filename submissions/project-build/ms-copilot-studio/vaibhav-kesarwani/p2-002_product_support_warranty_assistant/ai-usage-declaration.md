# AI Usage Declaration

## Purpose

This document declares how Artificial Intelligence (AI) tools were used during the design, implementation, testing, and documentation of the **NovaRetail Product Support & Warranty Assistant** project. All AI-generated outputs were reviewed, validated, and manually refined before inclusion in the final submission.

---

# AI Tools Used

The following AI tools were used during the project:

- ChatGPT (OpenAI GPT-5.5)
- Microsoft Copilot Studio (Generative AI capabilities)

---

# AI-Assisted Activities

AI tools were used to assist with the following activities:

- Brainstorming the overall chatbot architecture.
- Refining conversational flows and decision logic.
- Drafting project documentation.
- Creating sample trigger phrases.
- Assisting in the design of custom topics and reusable subtopics.
- Improving wording, formatting, and technical documentation.
---

# AI-Generated Content

AI-assisted content included:

- Project documentation.
- Known limitations documentation.
- README and project support documents.
- Test case templates and CSV generation.
- Copilot Studio prompt drafts.
- Conversation flow recommendations.

All generated content served as a starting point and was not submitted without review.

---

# Validation Process

Every AI-generated response was manually validated against:

- The official Project Requirement Document (PRD).
- NovaRetail business rules.
- Microsoft Copilot Studio implementation.
- Official Lenovo documentation.
- Official HP documentation.
- NovaCare Limited Warranty Policy.
- Product Support Scope.
- Product Safety and Escalation Policy.

Only validated information was included in the final solution.

---

# Manual Corrections

Significant manual modifications were performed throughout the project, including:

- Correcting AI-generated inaccuracies.
- Aligning documentation with PRD requirements.
- Refining chatbot conversation flows.
- Configuring knowledge sources in Copilot Studio.
- Creating and configuring custom topics.
- Designing reusable subtopics.
- Implementing conversation variables and branching logic.
- Defining validation rules and escalation paths.
- Organizing documentation into the required project structure.
- Reviewing generated responses for consistency and correctness.

---

# Manual Implementation Work

The following work was completed manually in this project:

- Creating the Copilot Studio agent.
- Configuring knowledge source groups.
- Uploading PDF and Markdown knowledge sources.
- Configuring public website knowledge sources.
- Designing custom topics.
- Creating reusable subtopics.
- Defining conversation variables.
- Implementing branching conditions.
- Configuring redirections between topics.
- Creating support summaries.
- Configuring generative answer nodes.
- Restricting knowledge source usage.
- Testing and validating chatbot behavior.
- Debugging conversation flows.
- Publishing and verifying the chatbot.

---

# Declaration

AI tools were used solely to assist with ideation, documentation, drafting, and development support. Final design decisions, chatbot implementation, validation, testing, and project submission were completed through manual review and verification to ensure compliance with the project requirements and the NovaRetail Product Support & Warranty Assistant specification.
