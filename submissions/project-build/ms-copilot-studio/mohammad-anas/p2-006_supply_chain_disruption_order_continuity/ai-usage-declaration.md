# Purpose

This document declares the use of Artificial Intelligence (AI) tools during the design, implementation, documentation, and validation of the **P2-006 – Supply Chain Disruption Order Continuity** project.

The AI tools were used solely as development assistants to improve productivity, documentation quality, technical understanding, and troubleshooting. All architectural decisions, workflow implementation, agent configuration, and testing were reviewed, validated, and implemented by the participant.
