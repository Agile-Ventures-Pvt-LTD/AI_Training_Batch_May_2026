# Limitations

The NovaCare Product Support Assistant has the following limitations:

- **No Live Warranty Lookup:** The agent cannot access live warranty databases or verify real-time warranty status.
- **No Case Creation:** The agent cannot create or submit support, repair, warranty, or replacement cases.
- **No Repair Status:** The agent cannot view or provide real-time repair or service-request status.
- **Limited Product Coverage:** Model-specific support is limited to the **Lenovo ThinkPad E14 Gen 5** and **HP LaserJet Pro MFP M428-M429**, along with supported bundled accessories within the defined scope.
- **No Final Decisions:** Warranty results are preliminary. Final approval, rejection, repair, replacement, or commercial decisions require validation by an authorised human representative.
- **No Emergency Integration:** The agent can identify safety-critical situations and recommend urgent escalation but is not directly integrated with emergency services.
- **No Inventory Visibility:** The agent cannot check real-time product, replacement-unit, spare-part, or accessory availability.

The agent must clearly communicate these limitations and must not claim access to systems or capabilities that have not been integrated.
