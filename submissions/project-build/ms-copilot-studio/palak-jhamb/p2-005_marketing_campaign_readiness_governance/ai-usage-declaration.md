# AI Usage Declaration

## Project Title

**Campaign Readiness Assessment Supervisor using Microsoft Copilot Studio**

---

# Purpose

This document declares the use of Artificial Intelligence (AI) technologies during the design, development, documentation, and implementation of this project. It ensures transparency regarding the role of AI while clearly identifying the work completed manually by the project author.

---

# AI Technologies Used

The following AI tools were used during the project:

| Tool | Purpose |
|------|---------|
| ChatGPT (OpenAI) | Design assistance, prompt engineering, documentation drafting, workflow planning, debugging support, and technical guidance |
| Microsoft Copilot Studio | Development of the Supervisor Agent, specialist agents, topics, AI prompts, orchestration, and autonomous workflows |
| AI Builder Prompt | Validation of campaign records using natural language instructions |

---

# Scope of AI Assistance

Artificial Intelligence was used as a development assistant throughout the project. AI-generated content was reviewed, modified, and integrated by the project author.

AI assistance included:

- Brainstorming the overall solution architecture.
- Designing the multi-agent workflow.
- Drafting supervisor and specialist agent instructions.
- Creating AI validation prompts.
- Generating technical documentation.
- Reviewing workflow logic.
- Assisting with debugging and troubleshooting during implementation.
- Improving documentation quality and formatting.

---

# Manual Work Performed

The following work was completed manually by the project author:

- Designing the overall project requirements.
- Creating the Microsoft Copilot Studio solution.
- Configuring the Supervisor Agent.
- Developing custom topics.
- Configuring Excel Online connector tools.
- Creating Power Automate workflows.
- Building AI Builder prompts.
- Testing and validating workflow execution.
- Debugging implementation issues.
- Configuring variables, conditions, loops, and orchestration logic.
- Preparing datasets for campaign assessment.
- Reviewing and validating all AI-generated content before inclusion.

---

# AI Usage Principles

The following principles were followed throughout the project:

- AI-generated content was reviewed before use.
- AI outputs were modified where necessary to align with project requirements.
- Technical decisions remained under the control of the project author.
- AI was used to improve productivity and documentation quality rather than replace implementation effort.

---

# Academic Integrity

The project represents the independent work of the author. Artificial Intelligence was used as a supporting development tool for ideation, documentation, and technical guidance.

The implementation, configuration, testing, validation, and integration of Microsoft Copilot Studio components were performed by the project author.

---

# Limitations of AI Assistance

AI-generated content may occasionally:

- Produce implementation approaches requiring manual verification.
- Suggest multiple possible solutions for platform-specific issues.
- Require adaptation to Microsoft Copilot Studio capabilities.
- Require manual testing before deployment.

Accordingly, all AI-generated recommendations were reviewed and validated prior to implementation.
