# AI Usage Declaration

## AI Tools Used

The following AI tool was used during the development of this project:

- **ChatGPT (OpenAI)**

---

# How AI Assisted the Development

ChatGPT was used as a development assistant to support the implementation and documentation of the project. AI assistance included:

- Designing the autonomous workflow.
- Structuring the Microsoft Copilot Studio agent instructions.
- Drafting connector tool descriptions.
- Preparing project documentation in Markdown.
- Generating sample test cases and evaluation data.
- Assisting with debugging and implementation guidance.

AI was used only as a supporting tool and not as a replacement for implementation or validation.

---

# Manual Validation Performed

All AI-generated content was manually reviewed and verified before submission.

The following items were validated:

- Agent instructions
- Knowledge source configuration
- Outlook, Excel, and Word connector setup
- Qualification workflow
- Duplicate detection logic
- Lead classification
- Human review workflow
- Test case execution
- Project documentation

The autonomous agent was tested using the required evaluation scenarios to ensure the generated content aligned with the project requirements.

---

# Corrections Made to AI-Generated Content

The following manual changes were made after reviewing AI-generated suggestions:

- Updated the agent instructions to match the final implementation.
- Modified tool names to use the exact names configured in Microsoft Copilot Studio.
- Refined the execution workflow to align with the project requirements.
- Adjusted documentation structure and formatting.
- Reviewed and corrected qualification logic and testing details.
- Verified all project deliverables before submission.

---

# Declaration

AI was used to assist with documentation, prompt design, implementation guidance, and content drafting. All implementation decisions, configuration, testing, validation, and final submission were reviewed and completed manually to ensure correctness and compliance with the project requirements.
