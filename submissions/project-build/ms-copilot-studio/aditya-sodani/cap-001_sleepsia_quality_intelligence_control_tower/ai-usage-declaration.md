# AI Usage Declaration

## AI Tools Used

The following AI tools were used during development of the Sleepsia Quality Intelligence Control Tower:

- ChatGPT
- Microsoft Copilot Studio AI capabilities
- Microsoft Learn MCP / AI-assisted documentation retrieval

## Areas Where AI Assistance Was Used

AI assistance was used for:

- Solution and architecture planning
- Supervisor–Specialist orchestration design
- Custom topic and workflow design
- Copilot Studio YAML drafting and troubleshooting
- Condition and variable design
- Test-case generation
- Error analysis and debugging guidance
- Documentation preparation
- MCP configuration guidance
- Tool integration guidance for Excel, Word and Outlook

## Human Validation

AI-generated suggestions were not treated as final implementation without validation.

The participant:

- Implemented the required topics in Microsoft Copilot Studio.
- Reviewed and modified generated YAML and expressions.
- Tested topic branches using representative chat queries.
- Verified specialist-agent outputs.
- Validated quality-decision precedence.
- Tested CAPA planning and ownership logic.
- Tested selective reassessment behavior.
- Verified `ReassessmentCount > 2` routing to Manual Review.
- Tested configured tools and data retrieval where implemented.
- Recorded defects identified during testing.

## Validation Evidence

Validation was performed using:

- Copilot Studio test chat
- Topic testing
- Specialist-agent outputs
- Evaluation test cases
- Tool execution results
- Reassessment test scenarios

Test results are documented in `test-report.md`.

## AI Validation Statement

AI assistance was used as a development and documentation aid. The final solution was reviewed, implemented, and tested by the participant in Microsoft Copilot Studio.

Any AI-generated implementation suggestions were validated against the project requirements, configured policy rules, actual agent behavior, and executed test results before being included in the final submission.
