# P2-001 – NovaHR Assist

## Project Overview

**Project Name:** NovaHR Assist

**Platform:** Microsoft Copilot Studio

NovaHR Assist is an AI-powered HR Employee Assistance chatbot developed using Microsoft Copilot Studio. The chatbot uses Retrieval-Augmented Generation (RAG) to provide policy-based responses by retrieving information from approved HR knowledge sources.

The chatbot assists employees with:
- HR policy questions
- Leave policy guidance
- Workplace concerns
- Remote work policies
- Employee benefits
- Attendance policies
- General HR procedures

---

# Objectives

The objective of this project is to build an HR chatbot that:

- Answers employee HR queries accurately.
- Uses only approved company knowledge sources.
- Handles workplace concerns safely.
- Provides leave guidance without approving leave.
- Follows responsible AI practices.

---

# Features

- Retrieval-Augmented Generation (RAG)
- Company policy-based responses
- Leave Request Advisor
- Workplace Concern & Escalation
- Source-grounded responses
- Safe conversational design
- Privacy-aware responses

---

# Knowledge Sources

- NovaWorks HR Policy Addendum
- Employee Handbook / HR Policy PDF
- Company HR Website

Knowledge precedence:

1. NovaWorks HR Policy Addendum
2. Employee Handbook
3. HR Website

---

# Responsible AI

The chatbot:

- Does not investigate complaints.
- Does not approve leave.
- Does not provide legal advice.
- Does not request sensitive personal information.

---

# Limitations

- Cannot access employee records.
- Cannot submit leave requests.
- Cannot contact emergency services.
- Cannot investigate workplace incidents.
