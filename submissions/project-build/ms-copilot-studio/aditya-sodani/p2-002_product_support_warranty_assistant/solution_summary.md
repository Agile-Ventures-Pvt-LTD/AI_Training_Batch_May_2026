# Solution Summary

## Project

**Product Support and Warranty Assistant**

## Objective

The Product Support and Warranty Assistant is a Microsoft Copilot Studio chatbot that helps customers troubleshoot supported Lenovo laptops and HP printers while performing a preliminary warranty eligibility assessment based on NovaCare policy.

## Key Features

- Guided troubleshooting for Lenovo laptops and HP printers
- Safety assessment before troubleshooting
- Product validation
- Preliminary warranty assessment
- Warranty classification
- Service route recommendation
- Support case summary generation

## Supported Products

- Lenovo Laptop
- HP Printer

## Main Topics

### 1. Guided Product Troubleshooting
Provides issue-specific troubleshooting based on the selected product and problem.

### 2. Warranty Eligibility and Service Route Assessment
Collects warranty information, validates customer inputs, applies warranty rules, and recommends the appropriate service route.

## Technologies Used

- Microsoft Copilot Studio
- Microsoft Power Platform
- Lenovo Product Manuals
- HP Product Manuals

## Outcome

The chatbot successfully provides structured troubleshooting guidance, performs preliminary warranty assessments, follows safety-first principles, and routes customers to the appropriate support path without making final warranty decisions.
