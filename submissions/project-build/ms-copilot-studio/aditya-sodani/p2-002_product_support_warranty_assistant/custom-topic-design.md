# Custom Topic Design

## Overview

The chatbot consists of two custom topics that provide guided product support and a preliminary warranty assessment for supported Lenovo laptops and HP printers.

---

## Topic 1: Guided Product Troubleshooting

### Purpose

Help customers diagnose and troubleshoot common laptop and printer issues while ensuring user safety.

### Main Flow

1. Select product family
2. Enter product model
3. Select issue category
4. Perform safety assessment
5. Provide issue-specific troubleshooting
6. Confirm whether the issue is resolved
7. Generate a support case summary or recommend escalation

### Supported Issues

**Lenovo Laptop**
- No Power
- Charging
- Battery
- Display
- Wi-Fi
- Keyboard
- Touchpad
- Overheating
- Performance
- Other

**HP Printer**
- Paper Jam
- Printer Offline
- Print Quality
- Power Issue
- Network/Wi-Fi
- Scanner Issue
- Ink/Toner
- Error Message
- Slow Printing
- Other

---

## Topic 2: Warranty Eligibility and Service Route Assessment

### Purpose

Perform a preliminary warranty assessment using NovaCare policy and recommend the appropriate service route.

### Main Flow

1. Collect product information
2. Validate purchase details
3. Check warranty coverage period
4. Identify exclusions and special cases
5. Perform preliminary warranty classification
6. Recommend the appropriate service route
7. Generate a warranty assessment summary

---

## Design Principles

- Guided conversation flow
- Safety-first approach
- Structured decision making
- Preliminary assessment only
- Human escalation when required
- No live system integration
