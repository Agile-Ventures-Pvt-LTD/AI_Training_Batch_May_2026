# AI Usage Declaration

## Overview

This project was developed using Microsoft Copilot Studio and AI-assisted tools to support the design, implementation, and documentation process.

## AI Assistance

AI was used to assist with:

- Designing conversation flows
- Drafting chatbot responses
- Creating troubleshooting workflows
- Preparing project documentation
- Generating test cases and test reports
- Reviewing and refining documentation

## Manual Work

The following activities were completed manually by the project author:

- Configuring the chatbot in Microsoft Copilot Studio
- Creating custom topics
- Implementing conversation logic and branching
- Configuring knowledge sources
- Testing the chatbot against project requirements
- Validating outputs and making corrections

## Declaration

All AI-generated content was reviewed, validated, and modified where necessary. The final chatbot implementation, testing, and submitted documentation represent the author's work and comply with the project requirements.
