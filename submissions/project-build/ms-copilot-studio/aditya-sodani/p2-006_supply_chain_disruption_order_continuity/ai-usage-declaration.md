# P2-006 — AI Usage Declaration

## AI Tools Used

The project used both Microsoft Copilot and ChatGPT as AI-assisted development tools.

### Microsoft Copilot

Microsoft Copilot was used to support:

- Agent creation and instruction development.
- Custom topic generation and topic-flow design.
- Topic configuration and refinement.
- Orchestration logic development.
- Agent and topic behaviour review.
- Assistance with configuring the autonomous multi-agent workflow.

### ChatGPT

ChatGPT was used to support:

- Agent instruction development.
- Specialist-agent design.
- Custom-topic flow design.
- Orchestration-flow planning.
- Business-rule and decision-logic structuring.
- Tool and integration planning.
- Test-case preparation.
- Debugging and implementation guidance.
- Project documentation preparation.
- Project documentation structuring.
- Review and refinement of implementation-related content.

## Scope of AI Assistance

AI assistance was primarily used for:

1. Designing and refining agent instructions.
2. Designing custom-topic flows.
3. Structuring Supervisor-to-specialist orchestration.
4. Planning sequential, parallel fan-out/fan-in, conditional, and reassessment flows.
5. Structuring deterministic business rules and decision logic.
6. Preparing and organising project documentation.
7. Preparing and organising test scenarios and test documentation.
8. Supporting troubleshooting and implementation decisions during development.

AI assistance was used as a development aid and did not replace the required project implementation or validation activities.

## Human Responsibility

The project team remained responsible for:

- Final agent configuration.
- Final specialist-agent configuration.
- Final topic implementation.
- Business-rule implementation.
- Tool and connector configuration.
- Excel, Word, and Outlook integration.
- Autonomous trigger configuration.
- Validation of the implemented solution.
- Test execution.
- Review of AI-generated content.
- Verification of project behaviour against the PRD.
- Review of generated documentation.
- Final submission.

AI-generated suggestions and content were reviewed, modified where necessary, and adapted to the P2-006 project requirements, supplied dataset, NovaSphere Supply Continuity Policy, and actual implementation.

The final implementation and project decisions were made and validated by the project team.
