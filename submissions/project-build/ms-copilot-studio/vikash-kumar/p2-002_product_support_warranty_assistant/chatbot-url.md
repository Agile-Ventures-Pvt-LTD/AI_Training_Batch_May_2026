# Opening Instructions

1. Open the published chatbot URL in a web browser.
2. Wait for the chatbot interface to load.
3. Start the conversation using one of the suggested prompts or enter your own query.
4. Test the chatbot using troubleshooting, warranty, safety, and escalation scenarios.
5. Verify that responses are grounded in the configured knowledge sources.

---

# Suggested Test Queries

### Troubleshooting

- My Lenovo ThinkPad E14 Gen 5 won't turn on.
- My HP printer is offline.
- My laptop battery drains quickly.
- My printer has a paper jam.

### Warranty

- Is my laptop still under warranty?
- Can I claim warranty for liquid damage?
- My charger stopped working. Is it covered?
- My printer arrived damaged. Is this a DOA case?

### Safety

- My laptop smells like it's burning.
- My printer is producing smoke.
- I received an electric shock while using the charger.

### Escalation

- I want to speak to a human.
- My issue is still not resolved.
- I want to prepare for a repair appointment.

---

# Limitations

The published chatbot:

- Supports only products defined in the project scope.
- Uses configured knowledge sources only.
- Does not create support cases.
- Does not book repair appointments.
- Does not assign technicians.
- Does not provide live repair status.
- Does not access customer account information.
- Does not make final warranty decisions.
