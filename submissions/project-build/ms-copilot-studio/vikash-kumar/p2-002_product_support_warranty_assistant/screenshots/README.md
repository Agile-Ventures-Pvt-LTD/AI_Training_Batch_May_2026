# Screenshot Evidence

This document lists the screenshots included with the project submission and explains the purpose of each image.

| Screenshot | Description |
|------------|-------------|
| **agent-overview.png** | Displays the Microsoft Copilot Studio agent overview, including the chatbot name, description, welcome message, and overall configuration. |
| **agent-instructions.png** | Shows the system instructions configured for the chatbot, including grounding rules, safety behaviour, warranty boundaries, response guidelines, and escalation policies. |
| **knowledge-sources.png** | Shows all configured knowledge sources, including the NovaCare policy documents, product manuals, and official Lenovo and HP support websites used for Retrieval-Augmented Generation (RAG). |
| **troubleshooting-topic.png** | Displays the implementation of the **Guided Product Troubleshooting and Safety Triage** topic, including information collection, product validation, safety assessment redirection, troubleshooting branches, and controlled troubleshooting flow. |
| **warranty-topic.png** | Displays the implementation of the **Warranty Eligibility and Service Route Assessment** topic, including warranty information collection, validation logic, preliminary classification, and service route determination. |
| **safety-subtopic.png** | Shows the reusable **Product Safety Assessment** subtopic used by multiple workflows to identify safety-critical conditions and determine whether troubleshooting can safely continue. |
| **case-summary-subtopic.png** | Shows the reusable **Support Case Summary** subtopic, which generates a structured interaction summary for customer confirmation before completing the workflow. |
| **conditional-branches.png** | Demonstrates the conditional logic used within the chatbot, including branching based on product family, issue category, safety results, troubleshooting outcomes, and escalation conditions. |
| **grounded-laptop-answer.png** | Demonstrates a grounded troubleshooting response generated using Lenovo knowledge sources for a supported laptop issue. |
| **grounded-printer-answer.png** | Demonstrates a grounded troubleshooting response generated using HP knowledge sources for a supported printer issue. |
| **safety-escalation.png** | Demonstrates chatbot behaviour when a safety-critical condition is detected, including stopping troubleshooting and recommending immediate human assistance. |
| **published-agent.png** | Shows the successfully published chatbot and confirms that the agent is available for testing through the published web channel. |
