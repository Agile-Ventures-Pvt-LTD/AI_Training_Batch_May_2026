# AI Usage Declaration

## AI Tools Used

The following AI tools were used during the development of this project:

- Microsoft Copilot Studio 
- ChatGPT (OpenAI)

---

## How AI Assisted the Development

AI was used as a development assistant to support the implementation of the chatbot. It helped with:

- Drafting and refining agent instructions.
- Suggesting conversation flows for custom topics.
- Improving prompt wording and response clarity.
- Designing conditional logic for leave request and workplace concern workflows.
- Reviewing documentation and test cases.
- Identifying possible edge cases for chatbot testing.

AI was used only to assist the development process and not as a replacement for manual implementation or validation.

---

## Outputs Manually Validated

All AI-generated suggestions were reviewed before being incorporated into the project.

The following components were manually validated:

- Agent instructions
- Knowledge source configuration
- NovaWorks HR Policy Addendum
- Leave Request Advisor topic
- Workplace Concern and Escalation topic
- Employment Verification Request topic
- Conversation flow and branching logic
- Test case execution and chatbot responses
- Project documentation

Each chatbot response was verified against the configured knowledge sources to ensure it matched the expected HR policy.

---

## Corrections Made to AI-Generated Suggestions

Several AI-generated suggestions were modified during implementation to meet the project requirements.

The following changes were made:

- Updated agent instructions to align with the NovaWorks HR Policy Addendum.
- Added explicit knowledge source precedence to resolve policy conflicts.
- Refined chatbot responses to be concise and focused on HR policy guidance.
- Improved conversation flows by adding validation, confirmation, and conditional branching.
- Added safeguards for privacy, confidential information, prompt injection, and out-of-scope requests.
- Ensured workplace concern conversations followed safe escalation practices without requesting unnecessary personal details.
- Verified that leave-related conversations provide policy guidance only and do not approve leave requests.
- Reviewed all generated content to remove unsupported assumptions and ensure consistency with the project requirements.

---

I confirm that AI tools were used only as development aids.
