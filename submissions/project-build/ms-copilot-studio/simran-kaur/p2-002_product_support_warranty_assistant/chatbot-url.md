# Opening Instructions

To access the chatbot:

1. Open the published chatbot URL in a supported browser.
2. Sign in if authentication is required by the Microsoft tenant.
3. Start the conversation using the welcome message or conversation starters.
4. Select the required support area:
   - Product troubleshooting.
   - Warranty assessment.
   - Product information.
5. Provide requested product details when prompted.
6. Follow the guided conversation flow.

---

# Supported Conversation Starters

Users can begin with examples such as:

- "I need help troubleshooting my laptop."
- "My printer is not working."
- "I want to check warranty eligibility."
- "I need help with a product feature."

---

# Limitations

The chatbot has the following limitations:

- No live warranty database integration.
- Cannot retrieve real purchase history.
- Cannot create actual repair tickets.
- Cannot provide live repair status.
- Cannot schedule technician visits.
- Cannot check inventory availability.
- Cannot approve or reject warranty claims.
- Cannot guarantee replacement or repair outcomes.
- Supports only configured NovaRetail product models.
- Does not provide emergency service integration.
- Final warranty decisions require authorised human validation.
