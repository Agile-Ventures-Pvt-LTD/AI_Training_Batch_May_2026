# Custom Topic Design

## Topic 1

### Name
TOP_Guided_Product_Troubleshooting_and_Safety_Triage

### Purpose
Capture product details, perform safety assessment, provide troubleshooting guidance, and recommend escalation when needed.

### Inputs
- Product Type
- Product Model
- Issue Category
- Symptom Description
- Power Status
- Error Code

### Outcomes
- Resolved
- Escalated
- Cancelled

## Topic 2

### Name
TOP_Warranty_Eligibility_Assessment

### Purpose
Provide a preliminary warranty assessment.

### Inputs
- Product Type
- Product Model
- Purchase Date
- Invoice Availability
- Damage Status

### Outcomes
- Preliminary Assessment Provided
- Assessment Cancelled

## Reusable Subtopic

### Name
SUB_Product_Safety_Assessment

### Purpose
Identify safety risks before troubleshooting.

### Checks
- Smoke
- Fire
- Electric Shock
- Liquid Exposure
- Physical Damage

### Outcomes
- Safe
- Level 4 Safety Escalation
