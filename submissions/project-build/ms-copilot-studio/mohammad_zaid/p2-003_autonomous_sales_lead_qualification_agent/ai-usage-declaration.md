
# AI Usage Declaration

## Project

NovaWorks Sales Lead Qualification Agent

---

# Purpose

This document declares the use of Artificial Intelligence (AI) tools during the design, implementation, documentation, and validation of the NovaWorks Sales Lead Qualification Agent in accordance with the project requirements.

The final solution was reviewed, configured, validated, and tested by the project author before submission.

---

# AI Tools Used

The following AI tools were used during the project:

| AI Tool                  | Purpose                                                                                                                                                   |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenAI ChatGPT (GPT-5.5) | Assisted with solution design, Copilot Studio configuration guidance, documentation drafting, workflow validation, debugging, and implementation support. |
| Microsoft Copilot Studio | Generated reasoning, executed agent instructions, orchestrated tool selection, extracted lead information, and performed autonomous workflow execution.   |

No other AI services or external language models were used during development.

---

# How AI Was Used

AI assistance was used to support the following activities:

## 1. Solution Design

ChatGPT was used to:

- Interpret the Product Requirements Document (PRD).
- Design the overall agent architecture.
- Recommend an appropriate tool structure.
- Define the agent workflow.
- Explain Microsoft Copilot Studio features.
- Assist with connector configuration.

Final implementation decisions were made manually after reviewing the PRD.

---

## 2. Instruction Design

ChatGPT assisted in creating and refining:

- Agent instructions
- Business rules
- Duplicate detection workflow
- Qualification logic
- Tool descriptions
- Operational workflow

Instructions were iteratively reviewed and updated to align with the PRD requirements.

---

## 3. Documentation

ChatGPT assisted in drafting the required project documentation, including:

- README
- Solution Summary
- Agent Instructions Design
- Trigger Design
- Tool Design
- Qualification Logic
- Known Limitations
- AI Usage Declaration
- Test Report template

All documentation was manually reviewed and edited where necessary before submission.

---

## 4. Troubleshooting

AI assistance was used to diagnose and resolve implementation issues, including:

- Excel Online (Business) connector configuration
- Word Online (Business) document generation
- Outlook trigger configuration
- Tool execution order
- Duplicate detection behaviour
- Microsoft Copilot Studio orchestration

Each recommendation was tested before being incorporated into the solution.

---

## 5. Validation

AI-generated suggestions were not accepted automatically.

Each configuration was manually validated by:

- Reviewing the PRD.
- Comparing behaviour against business requirements.
- Testing connectors within Copilot Studio.
- Inspecting generated Excel records.
- Verifying Word report creation.
- Confirming Outlook email delivery.

Only validated configurations were retained.

---

# Human Review and Responsibility

The project author remained responsible for:

- Understanding the PRD.
- Configuring Microsoft Copilot Studio.
- Creating and managing connectors.
- Implementing agent tools.
- Reviewing AI-generated content.
- Correcting inaccurate recommendations.
- Executing test cases.
- Verifying solution behaviour.
- Producing the final submission.

AI was used as a development assistant and not as an autonomous implementation tool.

---

# Corrections Made After AI Assistance

During implementation, several AI-generated recommendations were refined after practical testing, including:

- Simplifying the Excel tool architecture to separate read and write operations.
- Revising duplicate detection to align with the available Excel connector capabilities.
- Updating the agent instructions to enforce a deterministic workflow.
- Adjusting Word report generation to comply with connector limitations.
- Refining tool descriptions to improve Copilot Studio tool selection.

These changes were based on observed system behaviour and validation against the PRD.

---

# Data Privacy

Only the synthetic dataset supplied with the project was used during development.

No real customer information, credentials, API keys, authentication tokens, or confidential organisational data were processed or included in the solution.

---

# Compliance Statement

AI assistance was used solely to improve productivity, understanding, and documentation quality.

The submitted solution represents the final validated implementation created, configured, and verified by the project author.

All configuration, testing, and final review responsibilities remained with the project author.
