# AI Usage Declaration

## AI Tools Used

The following AI tools were used during the development of this project:

- **ChatGPT (OpenAI)** – Used to assist with solution design, documentation, architecture planning, workflow design, prompt refinement, and project documentation.
- **Microsoft Copilot Studio** – Used to build the Supervisor Agent, Specialist Agents, autonomous trigger, knowledge sources, tools, and overall multi-agent solution.

---

# How AI Assisted Development

AI was used as a development assistant throughout the project to:

- Design the overall multi-agent architecture.
- Define the Supervisor and Specialist Agent responsibilities.
- Draft and refine agent instructions.
- Design the autonomous assessment workflow.
- Document the solution architecture and implementation.
- Generate project documentation (README, architecture, solution summary, etc.).
- Create sample test cases and supporting documentation.
- Improve clarity, consistency, and formatting of technical documentation.

All generated content was reviewed, validated, and adapted to meet the project requirements before inclusion.

---

# Human Contribution

The project implementation, including agent configuration, tool integration, knowledge source setup, workflow orchestration, testing, validation, and final design decisions, was completed by the project author.

The author was responsible for:

- Configuring Microsoft Copilot Studio.
- Building the Supervisor Agent.
- Creating all Specialist Agents.
- Configuring tools and knowledge sources.
- Implementing the autonomous trigger.
- Testing and validating the end-to-end workflow.
- Reviewing and refining AI-generated content.
- Making all final implementation decisions.

# AI Usage Policy

AI assistance was used to improve productivity and documentation quality. All AI-generated outputs were reviewed and verified before being incorporated into the final solution. The final implementation and submitted project reflect the author's understanding and development effort.
