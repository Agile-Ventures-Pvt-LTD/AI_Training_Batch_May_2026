# Project Objective

The objective of this project is to build an AI-powered customer support agent in Microsoft Copilot Studio that assists customers with product troubleshooting, product safety assessment, and preliminary warranty eligibility guidance for laptops and printers.

The agent provides structured troubleshooting, identifies potential safety-critical situations, performs a preliminary warranty assessment, and recommends the appropriate support route while remaining compliant with company policies.

# Custom Topics

## 1. Guided Product Troubleshooting and Safety Triage

Purpose

Guide customers through structured troubleshooting while continuously monitoring for safety-critical symptoms.

Capabilities

- Collect product information
- Diagnose common issues
- Perform guided troubleshooting
- Detect safety conditions
- Recommend safe next steps
- Generate troubleshooting summary


## 2. Warranty Eligibility and Service Route Assessment

Purpose

Perform a preliminary warranty assessment and recommend the appropriate support route.

Capabilities

- Collect warranty information
- Validate purchase details
- Determine coverage period
- Check warranty exclusions
- Perform DOA assessment
- Recommend service route
- Generate warranty assessment summary
