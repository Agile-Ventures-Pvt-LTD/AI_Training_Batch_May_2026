1. Markdown Knowledge Base (Highest)
2. PDF Documents (High)
3. Official Vendor Websites (Medium)

The chatbot prioritizes internal policy documents for warranty, safety, and support scope before using product manuals or official support websites. This ensures responses remain consistent with the project requirements and business rules.
