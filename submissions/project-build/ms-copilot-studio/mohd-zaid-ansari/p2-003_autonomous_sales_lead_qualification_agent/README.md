# P2-003 – Mohd Zaid Sales Lead Qualification Agent

## Project Summary

This project is an Autonomous Sales Lead Qualification Agent built using Microsoft Copilot Studio.

The agent starts automatically when a new email arrives in Outlook with the subject **[P2-003 LEAD]**.

The agent:
- Reads the email.
- Checks if it is a sales lead.
- Gets lead details from the email.
- Checks for duplicate leads.
- Reads rules from Excel.
- Gives the lead a score and classification.
- Adds or updates the lead in Excel.
- Creates a Word report for Hot and Qualified leads.
- Sends the correct reply email.
- Sends difficult cases for human review.

This project uses only Microsoft Copilot Studio and Microsoft 365 tools.
