# AI Usage Declaration

## AI Tools Used

The following AI tools were used during the development of this project:

- ChatGPT (OpenAI)
- Microsoft Copilot Studio (Generative AI capabilities)

---

## How AI Assisted the Development

AI was used to support the development process in the following areas:

- Assisting with chatbot conversation design.
- Generating and refining prompt instructions for Prompt Nodes.
- Structuring chatbot topics and conversation flows.
- Drafting documentation, including the README and testing templates.
- Suggesting professional response wording for HR-related interactions.
- Providing guidance on configuring knowledge sources and Retrieval-Augmented Generation (RAG) behavior in Microsoft Copilot Studio.

---

## Outputs Manually Validated

The following AI-generated outputs were manually reviewed and validated before final implementation:

- Chatbot instructions and system prompts.
- Prompt Node classifications and routing logic.
- Custom topic conversation flows.
- Knowledge source configuration and retrieval behavior.
- HR policy responses generated by the chatbot.
- Project documentation, including the README and test report.

---

## Corrections Made to AI-Generated Suggestions

The following manual changes were made after reviewing AI-generated suggestions:

- Updated prompts to match the project requirements and HR policies.
- Refined conversation flows for improved user experience.
- Modified topic routing and classification logic where necessary.
- Corrected and validated chatbot responses against the configured knowledge sources.
- Revised documentation formatting, wording, and structure to meet submission requirements.
- Verified that all final responses aligned with the project objectives and implemented functionality.
