# AI Usage Declaration

## Permitted AI Assistance
AI assistance was used for:
- understanding project requirements;
- designing agent instructions;
- separating child-agent responsibilities;
- designing topic logic and variables;
- debugging implementation;
- generating test ideas;
- improving documentation.

## Responsibility
The participant remains responsible for the Copilot Studio implementation, configuration, testing and evidence.

## No Fabricated Evidence
AI must not be used to fabricate supplier approval, customer agreement, human approval, test evidence, screenshots, email delivery or successful tool execution.

## Final Verification
All submitted documentation must be checked against the actual Copilot Studio configuration and actual execution evidence.
