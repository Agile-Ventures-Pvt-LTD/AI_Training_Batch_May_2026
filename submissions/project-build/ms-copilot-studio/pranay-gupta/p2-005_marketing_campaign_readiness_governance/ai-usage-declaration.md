# AI Usage Declaration

## 1. AI Assistance

AI assistance was used for activities permitted by the project requirements, including:

- Understanding the PRD
- Designing agent instructions
- Designing child-agent responsibilities
- Designing topic flows
- Designing required variables
- Troubleshooting Copilot Studio implementation
- Generating test ideas
- Improving documentation

## 2. Participant Responsibility

The participant remains responsible for:

- Final Copilot Studio implementation
- Agent configuration
- Topic configuration
- Tool configuration
- Knowledge-source configuration
- Testing
- Screenshots
- Publication
- GitHub submission

## 3. Evidence Integrity

AI assistance must not be used to fabricate:

- Test evidence
- Screenshots
- Human approvals
- Connector execution results
- Published-agent evidence

## 4. Understanding

The participant must understand the implemented orchestration and be able to explain:

- Sequential processing
- Parallel fan-out/fan-in
- Hierarchical delegation
- Conditional routing
- Selective reassessment
- Failure/fallback handling
