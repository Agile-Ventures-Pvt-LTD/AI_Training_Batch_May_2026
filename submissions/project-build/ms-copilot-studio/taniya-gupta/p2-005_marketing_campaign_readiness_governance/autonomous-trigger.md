# Autonomous Recurrence Trigger Configuration

## Trigger Details
- **Trigger Type:** Recurring Copilot Trigger (`Recurrence`)
- **Interval:** Every 5 minutes (for Development & Testing)
- **Invocation Prompt:** `Check the Campaign_Requests table in Excel for the oldest Pending campaign. Run Campaign Intake & Validation and execute launch readiness assessment.`
- **Autonomy:** Runs completely without human intervention in the background.
