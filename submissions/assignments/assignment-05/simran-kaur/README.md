## Assignment / Project Title
AI Credit Card Management Agent Using LangGraph, Groq, Tools, and SQLite

## Description

This project demonstrates the development of an AI-powered SQL Agent using LangGraph and SQLite.

The agent takes natural language from users as input.It then decide which tool to call.
The project uses: 

```text
-ccms.db database
-prebuilt agent
```

The user query about the credit card management is sent to the llm. The agent then choose from various tool which are explicitly made and binded to agent. Based on the user query, appropriate tool is choosen. The result generated by tool is used by agent to generate response.

## How to Run

### 1. Clone the Repository

```bash
git clone <repository-url>
cd credit-card-agent-assignment
```

### 2. Create Virtual Environment


```bash
uv venv 
```

Activate:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
uv pip install -r requirements.txt
```


### 3. Configure Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_api_key
```

### 4. Run the Application

```bash
python -m app
```

### 5. Run Tests


```bash
pytest tests/test_tools.py

```
