Which customers have the highest amount due?

ASSISTANT:
Below is a **SQL query** you can run against the database to see which customers owe the most (i.e., have the highest total transaction amount to date).  

```sql
SELECT
    c.cust_id,
    c.first_name,
    c.last_name,
    SUM(t.TX_AMOUNT) AS total_amount_due
FROM
    customer      AS c
JOIN
    card          AS ca   ON ca.cust_id = c.cust_id          -- each card belongs to a customer
JOIN
    transaction   AS t    ON t.CARD_ID = ca.card_number       -- each transaction is linked to a card
GROUP BY
    c.cust_id,
    c.first_name,
    c.last_name
ORDER BY
    total_amount_due DESC          -- highest amount due first
LIMIT 10;                          -- top‑10 customers (adjust as needed)
```

### How it works
| Step | Explanation |
|------|-------------|
| **JOIN `customer` → `card`** | Links each customer to all of their cards (`cust_id`). |
| **JOIN `card` → `transaction`** | Pulls every transaction made with each of those cards (`CARD_ID`). |
| **`SUM(t.TX_AMOUNT)`** | Adds up every transaction amount for a given customer – this is the “amount due” (total spend). |
| **`GROUP BY`** | Aggregates the sum per customer. |
| **`ORDER BY … DESC`** | Sorts the result so the customers with the largest totals appear first. |
| **`LIMIT 10`** | Returns only the top‑10 customers; you can increase or remove this limit. |
