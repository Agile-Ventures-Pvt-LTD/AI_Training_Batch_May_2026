Question:  Show me the database schema.

Answer:
Here is the current database schema (tables and their columns):

| Table | Columns |
|-------|-----------------------------------------------------------------------------------------------------------------------------------|
| **customer** | `cust_id`, `first_name`, `last_name`, `email`, `phone`, `address`, `city`, `state`, `zip` |
| **netbanking** | `username`, `password`, `expiry_date`, `security_question`, `security_answer`, `cust_id` |
| **card_type** | `card_type_id`, `card_type`, `card_network`, `privilege` |
| **card** | `card_number`, `valid_from`, `expiry`, `security_code`, `x-coordinate`, `y-coordinate`, `mean_amount`, `std_amount`, `mean_nb_tx_per_day`, `cust_id`, `card_type_id` |
| **transaction_type** | `txn_type_id`, `debit_credit`, `lcl_intnl` |
| **transaction_terminal** | `TERMINAL_ID`, `x_terminal_id`, `y_terminal_id` |
| **merchant_type** | `id`, `merchant_type` |
| **merchant** | `id`, `merchant`, `merchant_type` |
| **transaction** | `Unnamed: 0`, `TXN_ID`, `TX_DATETIME`, `CARD_ID`, `TERMINAL_ID`, `TX_AMOUNT`, `TX_TIME_SECONDS`, `TX_TIME_DAYS`, `TXN_TYPE_ID`, `M_ID` |

These tables store customer profiles, net‑banking credentials, card details, transaction types, terminal locations, merchant information, and the transaction records themselves.
