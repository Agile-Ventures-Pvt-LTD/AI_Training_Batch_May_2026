# Jira MCP Assistant

A simple MCP (Model Context Protocol) server that connects an LLM with Jira Cloud. The host application accepts natural language queries, invokes the appropriate MCP tools, and returns human-readable responses.

# 1. Architecture

The objective of this assignment is to build:

- A Jira MCP Server using FastMCP that runs in stdio mode
- An MCP Host application that connects to this server
- An LLM-powered agent using Groq to answer natural language queries 
about Jira issues

This assignment has two components: 

| Component | Purpose |
|-----------|---------|
| Jira MCP | Exposes Jira tools using FastMCP / mcp-use in stdio mode. |
| Server MCP Host | Uses Groq LLM to connect to the MCP server and answer user queries. |

   **Architecture Flow**

```
                           User
                              │
                              ▼
                  mcp_client.py (Host)
                              │
                              ▼
                     MCPAgent (mcp-use)
                              │
                              ▼
                        Groq LLM
                              │
                  Selects Appropriate Tool
                              │
                              ▼
                  Jira MCP Server (FastMCP)
                              │
                              ▼
                     Jira REST API
                              │
                              ▼
                        Jira Cloud
```

# 2. MCP Server Setup

Install dependencies

```bash
pip install -r requirements.txt
```

The MCP server is implemented using **FastMCP**.

Available tools:

- list_projects
- search_issues
- get_issue_details
- get_issue_comments
- add_issue_comment
- update_issue_status

The server communicates with Jira using the Jira REST API.

---

# 3. Jira Configuration

Create a free Jira Cloud account.

Create a project (example):

```
Project Name : MCP Learning
Project Key  : SCRUM
```

Generate an API Token from your Atlassian account and create a `.env` file.

```text
JIRA_BASE_URL=https://your-domain.atlassian.net
JIRA_EMAIL=your_email@gmail.com
JIRA_API_TOKEN=your_api_token
```

---

# 4. Groq Setup

Create a Groq API key.

Add it to the `.env` file.

```text
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=llama-3.3-70b-versatile
```

The LLM is initialized in `src/llm.py`.

---

# 5. Running the MCP Server (stdio)

The server uses **stdio transport**.

It is started automatically by the host through `MCPClient`.

To run it manually:

```bash
python server/jira_mcp_server.py
```

---

# 6. Running the Host

Start the client application.

```bash
python -m src.host.py
```

You will be prompted to enter queries interactively.

Example:

```
Jira MCP Assistant

Enter your query:
```

# Output

Every response generated by the assistant is stored in:

```
output/jira_output.json
```

Example:

```json
{
    "user_query": "List all projects",
    "tools_used": [
        "list_projects"
    ],
    "final_answer": "The only project available is MCP Learning (SCRUM).",
    "write_action_performed": false
}
```
