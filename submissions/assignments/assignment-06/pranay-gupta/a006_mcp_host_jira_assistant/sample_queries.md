# Jira MCP Host - Sample Queries

Use the following sample queries to interact with the Jira Issue Assistant.

---

## Project Queries

- List all Jira projects.
- Show all available projects.

---

## Issue Search

- Show all open issues.
- Show high priority issues.

---

## Issue Details

- Summarize issue ABC-12.
- Show complete details of issue ABC-12.

---

## Comments

- Show comments for issue ABC-12.
- Add a comment to ABC-12 saying "QA validation is pending."

---

## Status Update

- Update issue ABC-12 status.
- Move ABC-12 to Done.

---

## Exit

To close the application, type:

- `exit`
- `quit`
