# Jira Issue Assistant - Sample Operational Queries

This file contains test queries categorized by their operational intent. Use these strings as inputs for `src/host.py` to verify the automated tool routing and agent multi-turn execution behaviors.

---

## Read & Search Queries

### 1. Show all issues
```
"Show all issues"
```

### 2. Show open issues
``` 
"Show todo status in Project LT"
```

### 3. List all Jira projects
``` 
"List all Jira projects"
```

### 4. Show high-priority issues
```
"Show high-priority issues"
```

### 5. Summarize an issue
```
"Summarize an issue LT-01"
```

### 6. Show comments
```
"Show comments for the issue LT-02"
```

### 7. Show assigned issues
```
"Show assigned issues for Ashish Sinha"
```
