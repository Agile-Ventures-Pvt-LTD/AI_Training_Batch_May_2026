# A006 - MCP Host for Jira Issue Assistant

## Overview

This project implements a **Jira Issue Assistant** using the **Model Context Protocol (MCP)**.

The application consists of two major components:

1. **Jira MCP Server**
   - Built using **FastMCP**
   - Exposes Jira operations as MCP tools
   - Runs in **stdio** mode
   - Communicates with Jira using the Jira REST API

2. **MCP Host**
   - Built using **mcp-use**
   - Uses **Groq LLM** for natural language understanding
   - Selects appropriate MCP tools
   - Generates human-readable responses

The assistant never hallucinates Jira information. All Jira-related answers are generated using MCP tools.

# Jira MCP Tools

The server exposes the following six tools:

| Tool | Description |
|------|-------------|
| list_projects | Lists all Jira projects |
| search_issues | Searches issues using JQL |
| get_issue_details | Retrieves issue details |
| get_issue_comments | Retrieves issue comments |
| add_issue_comment | Adds a comment to an issue |
| update_issue_status | Changes the issue status |

JIRA_EMAIL=your_email

# Installation

Clone the repository.

```
git clone <repository-url>
```

Move into the project.

```
cd a006_mcp_host_jira_assistant
```

Create a virtual environment.

Windows

```bash
uv .venv
```

Activate it.

Windows

```bash
.venv\Scripts\activate
```

Install all dependencies.

```
uv pip install -r requirements.txt
```

# Configure Jira

Create your own Jira Cloud account.

Create one or more projects.

Create some dummy issues.

Generate a Jira API Token.

Update the `.env` file with:

- Jira Base URL
- Jira Email
- Jira API Token

# Running the Jira MCP Server

Run the MCP server from the project root.

```
python server/jira_mcp_server.py
```

The server starts in **stdio mode** and waits for requests from the MCP Host.

---

# Running the MCP Host

Open another terminal.

Activate the virtual environment.

Run

```
python src/host.py
```

The application will prompt:

```
Enter your query:
```

Example:

```
List all Jira projects
```

or

```
Show all open high-priority issues
```

Type

```
exit
```

to stop the host.

# Working Flow

1. User enters a natural language query.
2. Groq LLM understands the intent.
3. Appropriate MCP tool is selected.
4. MCP Host sends the request to the Jira MCP Server.
5. Jira MCP Server communicates with Jira REST API.
6. Jira returns the requested information.
7. The final response is displayed to the user.
8. The response is saved inside the `outputs` folder.
