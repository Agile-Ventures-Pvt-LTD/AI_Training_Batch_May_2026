# Sample Queries

Use the following queries to test the Jira MCP Host Assistant.

## Read Operations

List all Jira projects
Show open issues
Show high-priority issues
Summarize issue AP-1
Show comments for AP-1
Show issues assigned to me

## Write Operations

Add a comment to AP-1 saying "QA validation is pending."
Update the status of AP-1 to "In Progress"

Note: Replace `AP-1` with a valid issue key from your Jira project if needed.
